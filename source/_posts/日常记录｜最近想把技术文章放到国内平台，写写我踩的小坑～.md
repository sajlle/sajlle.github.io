最近投简历，想把技术文章单独拎出来。毕竟这个博客个人信息太多，也有不方便给HR和面试官看的地方。
第一个方案是单独做个技术博客。做好了，挂在Vercel上，结果国内不翻墙打不开。主站GitHub Pages也一样，国内访问时灵时不灵。

用国内云服务器倒是稳，但得备案。我不想走这套对我来说太重的流程，也不想自己承担内容运营的主体责任。那就只剩第二个方案：发到国内平台，备案和合规让平台去操心。代价是发文、建专栏都得走平台的流程，不过总比备案轻松。

克和G都推荐掘金，我就手动搬了几篇过去。问题是网页端编辑器会随机解析失败，同一份markdown贴进去，时好时坏。
人肉搬运不是长久之计。所以眼下简历先挂Vercel博客，下一步试试写脚本直接推掘金草稿箱。

以前写博客只顾吭哧吭哧写，没想过给谁看。今天头一回想给国内面试官看，才发现要额外做这么多工。
不过也能安慰自己，这不是额外做工，这是再提前实验自媒体发文摩擦系数。

但目前我还没打算认真运营自媒体。
主要是没有精力。其次是如果运营，会吃掉持续写作的乐趣。

运营本身会要求人去考虑：
1. 有没有人看。
2. 这篇流量如何。
3. 研究平台推荐算法。
4. 研究怎么蹭热点
5. 研究怎么涨粉丝

这些一考虑，那写作本身就不是主角了。

再，运营不只是要适配平台，还要适配人设。
我拿人设举例子。比如本博客中秋前一天的文章：[日常记录｜中秋节 Surprise：Anthropic 给我发了 100 刀云算力月饼](https://sajlle.github.io/2026/09/24/%E6%97%A5%E5%B8%B8%E8%AE%B0%E5%BD%95%EF%BD%9C%E4%B8%AD%E7%A7%8B%E8%8A%82-Surprise%EF%BC%9AAnthropic-%E7%BB%99%E6%88%91%E5%8F%91%E4%BA%86-100-%E5%88%80%E4%BA%91%E7%AE%97%E5%8A%9B%E6%9C%88%E9%A5%BC/)
内容就是：
> 领两份 AI 福利 → 写段子 → HR 联系 → 玩生图

本人原版写的是：
```markdown
A 社给我发月饼
→ 我拿 A 社开涮
→ 吃人嘴短，良心发现
→ 决定把所有 AI 公司一起涮了，这下公平
→ 小克甚至主动给自己的公司补刀
→ 下午华为 HR 突然出现
→ 刚玩完“遥遥领先”，正主相关人士进入剧情
→ 公关部真人快打我跑，技术部真人快打我欢迎
→ 晚上无聊画两笔
→ 把 GPT 叫来给草稿装修
→ 博客后半截突然开始展示 AI 生产力。
```

如果换成「日常记录博主」人设，会写成这样：
```markdown
今年中秋收到 Anthropic 100 美元 credit，也获得了一次 Codex reset。
下午收到华为 HR 消息。
晚上试了下 GPT 生图，效果不错。
这个中秋还挺充实。
```

如果换成「科技博主」人设，大概是这样的：
```markdown
中秋期间 Anthropic 向 Pro 用户赠送 100 美元 API credit，OpenAI 也提供 Codex reset。
借此测试了 GPT 最新图像生成能力，从草图补全效果来看，构图保持和细节生成均有明显提升。

注：测试环境与Prompt如下...
```

如果换成「生活型的博主」人设，大概是这样的：
```markdown
《中秋被AI公司宠了一天是什么体验》
谁懂啊😭今年中秋没有月饼，但是 AI 公司给我发算力了！
```

```markdown

所有努力都不会白费，坚持学习技术，机会总会来的。
```
