# 强制度化童工化家庭的结构画像

## 系统定义
### 目标（表面）：
维持家庭生计，店面运转，家务效率，面子秩序
### 目标（真实）：
用“持续征用”制造可控性，稳定父母的焦虑与权威，降低对外部资源的依赖成本。
### 特征：
把孩子当作长期劳动力与情绪缓冲器，形成稳定排班机制（7–19岁、寒暑假、周末、全年执行）

## 输入
### 资源约束
- 现金流紧张/不稳定（或者对不稳定高度恐惧）
- 人手不足（或者不愿雇人/不信任外人/不想付出雇佣成本）

### 认知与价值观输入
- 闲着 = 败家/变坏/不听话
- 吃苦 = 正当性
- 孩子是家庭资产/劳动力储备

### 情绪输入
- 父母长期焦虑（钱/面子/亲戚比较/控制感不足）
- 对不确定性低耐受 -> 需要立刻做点什么来「看见掌控」

### 环境触发器
- 亲戚来访/面子局/装修/婚丧喜事/赶集旺季
- 任何「外部变动」都会提升系统压力，从而增强对孩子的征用频率

## 核心规则
### 角色先分配
- 我：可用/能干/该忍/该顶
- 我的价值不是「发展」，而是「可调度性」

这导致：贡献越多，责任越多，但权限不增加。【很典型的反激励】

### 时间不属于我（属于父母）
- 我的时间默认归家庭所有
- 个人时间需要「批准/赏赐」，且可以被随时撤销

### 「劳动 = 服从」的绑定
- 干活儿不仅是产出，更是服从验证
- 让我帮忙是为了确认权威，我是否依旧可调度

### 无补偿机制
- 别人家是「打一巴掌给一颗糖」
- 我家是「打一巴掌再骂一顿」
=> 系统不给出口，不提供可恢复的情绪回路

### 甩锅协议
- 建议者会被当作责任源头（我说一句 = 我该负责推进）
- 承担者回被当作默认义务（我做一次 = 我该一直做）
=> 系统鼓励：「不承担的人永远更安全」

### 断章取义接口
- 说话被截取成「可用于外部甩锅/内部指责」的片段
- 语言不是用来协作，而是用来博弈与责任转移
=> 语言成为高风险输入源头

## 执行流
1. 外部压力/内部焦虑上升
2. 父母启动「控制回路」：寻找可被立刻调度的对象
3. 选择最稳定可控资源 => 我
4. 以道德语言封装指令
   - 你闲着干嘛
   - 一家人还计较
   - 你不干谁干
5. 被拉进执行 -> 系统短期稳定（父母获得掌控感）
6. 我试图协商/表达 -> 被判为「管太多/顶嘴」
7. 系统通过争吵/羞辱/冷暴力把我压回可用状态
8. 周期循环，直到我出现跳轨行为

## 输出（系统产物）
### 对父母
- 即时掌控感（焦虑被转移）
- 获得廉价劳动力与情绪泄压对象
- 维持我在管家/我在当父母的叙事

### 对我
- 极强的逆境执行力与工具理性
- 对「被召唤/被打断」高度敏感
- 需要确认安全边界才能投入个人事务
- 对「解释/沟通」形成条件性恐惧（说话 = 被利用）

## 副作用
### 行为层
- 形成「先做出成果才配休息」的逻辑
- 容易进入「爆肝 -> 崩溃 -> 自责」循环
- 对家庭事务产生全面回避（因为参与 = 被吸血）

### 情绪层
- 休息羞耻感/闲置焦虑
- 对亲密关系的「被征用恐惧」
- 轻微的「反补偿冲动」：只要能自主，就想自主

### 关系层
- 家庭沟通变零和博弈
  - 我赢了=他们输了
  - 我解释=我给接口
  - 我沉默=自保
- 最终导向：退出式和平

## 系统的故障模式
### 自证预言（希腊神话模式）
父母为了防止独立而控制我
-> 控制过载
-> 我只能更激烈的跳轨独立
-> 父母说：「看吧，她就是要跑」
-> 控制更强（进一步加速分离）

### 反激励导致「能力惩罚」
我越是能干越被用，越被骂
-> 我的策略变成：不显能，不建议，不承担
-> 家庭效率更低，冲突更高
-> 父母更焦虑 -> 更想征用我（恶性循环）
