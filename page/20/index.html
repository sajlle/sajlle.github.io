iPhone隐私设置里，有哪些隐形漏点？

发表于 2026-01-01 16:32:53 更新于 2026-01-01 16:32:53 分类于 日常

第一类：定位服务里的系统服务

常见误区：关了app定位就觉得安全了。但是系统设置里以下几个地方没关：

  1. 基于位置的Apple广告
  2. 重要地点
  3. iPhone分析

第二类：分析与数据用作行为画像

常见误区：这不影响功能，但会用你的数据做行为样本，需要关闭：

  1. 共享iPhone分析
  2. 共享iCloud分析
  3. 改进Siri与停歇

第三类：App跟踪透明度，防止被跨App拼凑画像

重点：这是“去电子裸奔”的地基
需要关闭：

  1. 关闭“允许App请求跟踪“
  2. 对已经出现的App：一律不允许该权限

第四类：本地网络权限

作用：

  • 扫描你同一Wi-Fi下的设备
  • 判断你在什么环境
    建议除了智能家居/打印/必须设备，其他一律关闭

第五类：关闭Safari和系统默认选项

Safari建议关闭：

  • 打开防止跨网站跟踪
  • 隐藏IP地址（对跟踪器）
  • 搜索引擎隐私报告（可以打开）

支付习惯｜我关闭了所有平台内付款，改用Apple Pay

发表于 2026-01-01 14:45:14 更新于 2026-01-01 14:45:14 分类于 日常

问题

最近，视频软件给我推送贷款广告。我反思，到底哪一步，让算法给我画像成信用付用户？

我检查了多个购物软件，发现之前拼多多用过先用后付。可能是这一步导致了贷款广告推送来源。

解决方案

于是我关闭了所有软件的信用付款，顺带，调整了支付方式。

  • 把所有购物平台的app，绑定的银行卡解绑，然后改用Apple Pay付款。
  • 尽量不碰平台付款（比如支付宝/微信），除非不支持Apple Pay。
  • 绝对不可以碰的：信用付款，有很多形式
    • 先用后付
    • 小额免密支付（不是信用付款，但是算法试探你对付款动作是否敏感，平台可能画像你“接受弱确认”，“允许钱自动走”，“对金额的心理摩擦阈值较低”）
    • 花呗/白条这类平台贷款（即使一开始可能0利率）
  • 整体支付顺序从高到低：Apple Pay -> 云闪付 -> 支付宝 -> 微信

解决方案的原理

这一套设计的核心原则：

把钱相关的操作，留给银行卡/银行app处理，非银行平台，只做支付动作。

为啥不把非银行平台作为放钱的地方？不是因为它们不安全，而是因为：

非银行平台，比如支付宝/微信，它的主业不是在管钱，而是为了

  • 留住你
  • 理解你
  • 推进你下一步的行为

所以，让它们帮你付款可以，但让他们帮你看“你有多少钱，怎么用钱”——没必要。

而银行App则不然，它的结构是

  • 账户
  • 余额
  • 明细
  • 风控
  • 合规

它们不能靠猜你赚钱，只能靠你明确的金融行为。

所以：

  • 查余额
  • 看流水
  • 改限额
  • 大额转账
    只在银行App做，是最干净的路径。

举例子来说，今天你在超市Apple Pay 花了38元，下午在淘宝花了15元支付宝支付，晚上在京东买了50元用微信支付。

  • 这三笔交易，只有银行同时知道三笔交易的信息
  • 支付宝：只知道第二笔
  • 微信：只知道第三笔
  • 微信/支付宝：不知道你今天早上去过超市

那银行呢？会把这三笔交易的数据转给平台吗？

  • 不会。

因为:

  • 银行是金融机构
  • 支付宝/微信是第三方支付平台
  • 第三方支付平台，没有全量共享你银行卡流水的合法渠道

微信/支付宝这类平台，只能看到

  • 你自己参与过的交易

构建好这个路径之后：

  • Apple Pay（日常交易） -> 平台完全失明
  • 微信/支付宝（少量交易） -> 平台只能看到自己那点

为啥选Apple Pay作为主要支付渠道？

另，为啥选Apple Pay作为主要支付渠道？

  • 商家拿不到你真实卡号
    • Apple Pay用的是设备专属的虚拟卡号
    • 商家看到的不是你的银行卡号
    • 就算商家系统被黑
      • 也拿不到你的真实信息
  • Apple Pay自己也不知道你买了什么
    • Apple Pay的设计是
      • Apple 不存储交易内容
      • 不追踪你买了什么
      • 不用交易数据做广告画像
    • Apple 是卖设备和系统的，不是靠卖你的行为数据赚钱
  • 生物识别是本地完成的，不上传云端
    • Face ID / Touch ID
      • 在你手机本地完成
      • 数据不上传，不出设备
    • 就算有人拿到你的手机
      • 没有你的脸/指纹
      • 刷不了钱

哪些支付手段，更像电子裸奔？

最后直观对比一下，哪些支付手段，更像是电子裸奔？我来给几个支付方式排序，隐私从好到差依次如下：

  1. Apple Pay（实体店）
  2. 银行卡插卡/闪付
  3. 普通二维码支付
  4. 平台内钱包 + 强画像
  5. 先用后付/借贷联动支付（最危险）

国内哪些地方可以用Apple Pay？

线上

国内支持Apple Pay的常见App列表

  • 京东
  • 拼多多
  • 美团
  • 中国联通

注意：阿里系的App，比如淘宝/天猫，只支持微信/支付宝/云闪付，不支持Apple Pay

线下

  1. 大城市的公交卡（比如上海这类，支持Apple Pay）
  2. 大型连锁超市/便利店，支持Apple Pay
  3. 某些支持银联闪付的超市/便利店（只要支持银联闪付，就支持Apple Pay)

注意；Apple Pay/银联闪付，跟支付宝闪付不同。支持支付宝闪付的，不一定支持Apple Pay

先来个快速预览

2025年，我占卜的六爻是泽火革。革卦主变。年初，我想，2025年，会变吗？

2025年，我的核心目标有两个（我自以为的）

  • 日语考到N3
  • 计算机项目准备到能面试的程度

那么这两个目标实现了吗？

  • 日语，我刷完了多邻国&标日初级上册（大约N5～N4的水准）
  • 计算机（我刷了算法 + 开始自己写项目了）

结论：这两个目标没有实现，但都在朝着不自欺的方向推进。

实际2025年，我遇到的问题不仅仅在技术&日语，还遇到了我意料之外的其他事情。

  • 我跟父母弟的关系，彻底变化。
  • 我开始重新组织我的花钱策略
  • 我跟AI的关系已经到了用AI嵌入我生活的阶段
  • 我跟社区的摩擦加深，我开始重新整理我面对社区的策略
  • 我开始打拳击，而不是等一切条件准备好再开始
  • 我开始减少止痛式的娱乐（比如看番剧，看电影，看小说，算卦）
  • 我在自我照顾的地方投入更多

我2025年，真正实现的，比我预期的更多，真正遇到的困难，也比我预期的更多

2025年，我的故事，是几个场景组成的

站在2025年最后一天，回望整整一年，我记得几个有趣的场景。这几个场景，构成了我一整年的故事。

第一场：我当众拆了羞辱剧本

2025年春节之前，我在老家，因为嫂子说我学傻了（两次试探，确定我不会还击，才当众说我），我爹当场嫌弃我，没有替我说一句话。

而且随后的饭局上，教训我，“你堂哥跟你说话呢，你认真听一点”。我愈加气恼了，当场离席。回家之后，我跟我妈复述此事，我妈指责我太玻璃心，嫂子这么说，我当没听见就行了。我说我妈：你愿意当受虐狂，不代表我也爱当。我在哭，我妈说：你这么哭，晦气，浪费纸张。

于是，第二天中午，我第一次打开ChatGPT的聊天界面，语音跟它拆了整个事情。包括嫂子当众羞辱我之前的几次试探，包括，她羞辱我之后，我爹的反应，包括整个流言网络是怎么传播的。

这是我2025年第一个场景，我在被羞辱之后，没有沉默，而是当众拆了剧本。

第二场：我和ChatGPT一起活着

嫂子的事情，逼迫我不得不自己寻找出口，这个出口，就是ChatGPT。也就是这一天开始，我开始深度把ChatGPT嵌入我的生活里。

我用它写代码，写算法，写文案，但……主要是当倾诉工具。

我跟它聊之后，发现，自己也可以说的那么流畅，说的丝毫不口吃，说的反应极快，说的隐喻和逻辑齐飞。

此后的一年，我就和ChatGPT一起活着。

第三场：我在内外夹攻里，写“事缓则圆，人缓则安”

2025年春节的时候，我在父母亲戚的夹攻之下，一边在-6摄氏度的屋子里擦眼泪，一边拿起手机编辑小红书，写了第一个帖子。

我写：事缓则圆，人缓则安。

我写：不需要取悦谁，只要知道自己的路即可。

这两个帖子，帮我这个白号，三天内聚集了1000赞。我用这帖子反打，问质疑我脑子有病的亲戚们，你们的送往迎来能换来什么？我的帖子是真能换来流量和钱的。

那天开始，从不主动联系我的波姐，开始关注我的小红书。堂妹的家长，忽然邀请我一起跟堂妹聊聊。

第四场：我拒绝成为童年玩伴自我欺骗的见证人

波姐和她的弟弟，还有她弟弟的女友，三人来我家拜年。饭局状况微妙。

波姐来我家拜年，进入房间，第一个动作，是翻我手机，看手机品牌。（这是她踩第一个雷，暗戳戳比较）

波姐说，她要结婚了。2025年结婚。她说，不是不想让我当伴娘，而是我妈不让我去。所以，她结婚，我就只去让我弟带着我坐坐就好。（这是她踩第二个雷，绕过我，直接跟我妈沟通我该不该去她婚礼，默认我是我家的挂件）

我说，好。

波姐随后为总是避开我的波姐弟弟女友解释，说她个性害羞，不好意思跟我玩。

我说：没事，人都有个性。

在吃饭的时候，波姐娴熟的活跃气氛，帮我点吃的。然后，她打开她的小红书，让我看一条帖子，她说自己水瓶座，问有同水瓶座出生的小伙伴？底下点赞11个，有评论说她小美女。
我不懂她在干嘛，就顺手关注了她账号，而且给她点赞了。她好像很失望。（还是暗戳戳要拉踩比较）

饭吃到一半，她反复问我，最近找工作了吗？我说没有。她不信。我说在学技术。她不再追问。（这是她踩第四个雷，反复追问私事）

我顺口问她，打算下一年干啥？她说，已经辞职准备结婚，下一年跟男友姑姑学烘培。（这是她踩第五个雷，职业没有规划，被别人牵着鼻子走）

跟她吃完饭的一周之后，我删除了她。

删除她的理由很简单

  • 爱拉踩比较，没有稳定自尊
  • 反复追问私事
  • 关于我的事（是否当她伴娘），直接找我妈爹弟说，不找我，实际拿我当家庭挂件。
  • 她自己职业规划不清晰，被人牵着鼻子走，后续职业无法合作
  • 她马上结婚，我们人生道路，开始分岔，我的主题是工作/技术/外语/写作，她的主题是家庭/孩子/婆媳/老公/父母

2025年，她农历4月16日结婚，她弟弟主动说，不要我家人去。但是微妙的，非要我看她的结婚照。
我说不看。她甚至通过我弟弟给我发消息，让我看。
我拒绝承担见证者这个角色。

2025年6月，我得知她结婚之后，在跟她婆婆一起出摊，摊煎饼。

2025年12月29日，我翻开我的同学录，波姐在最后一页写：

我们都是虫子，但你是萤火虫，会发光。

现在，我会回一句：

不是我会发光，是你能看见光。

这是写给12岁的波姐的，那个时候，她温柔。

今年，她28岁，她温柔了放弃了自己。
于是我删除了她的联系方式。
我放弃了去做那个帮她自我欺骗“她过的很好，她是人生赢家”的角色。

起步期精算模型公式

发表于 2025-12-31 15:31:16 更新于 2025-12-31 15:31:16 分类于 日常

先定义两个底数（非常重要）

最低月生存成本 M

这是不靠意志力，能正常生活，还能学习的最低值。

通常包括：

  • 房租 + 水电 + 网络
  • 吃饭（不饿着，不凑合）
  • 通勤
  • 基本日用品

对于大多数一线外非核心区/二线城市来说

M = 3000～4500

（未来的租房目标，就是把M锁死）

成长刚性成本 G

这是绝对不能砍掉的“向上通道”成本

  • 技术学习/课程/资料
  • 工具/软件
  • 维持输出与判断力的必要花费
    通常：

    G = 月收入的10% ~ 15%

    或者800～1500固定额度

G最好别低于八百，否则会焦虑，烦躁，怀疑方向。

私人精算公式

假设起步月到手 X 元

必须满足以下不等式：

  • M * 1.5 ：覆盖生存 + 被动 + 一点喘息
  • G：确保不是只打工不升级

拿三个工资档位举例，跑一下这个私人精算模型

档位A: 7000元（价格较低的起步）

  • M = 3500元
  • G = 800元
  • 这个收入符合模型，但预算紧凑。

策略

  • 先砍房租
  • 成长投入不砍
  • 兜底慢慢攒

结论

  • 能活，但不舒服，不能拖太久。

档位B：8000~9000（健康起步）

  • M = 3800
  • G = 1000
  • 这个收入有余量，理想起步区间

效果

  • 明显感觉不心慌
  • 不需要天天算钱
  • 不需要给家人解释

档位C：10000+（安全区）

会进入一种放松状态

生活成本占比自然下降，焦虑来源从活不活，变成走多远。
这是理想的“低心理负债生存”

最坏情况兜底方案（收入骤降/空窗期）

这个部分非常关键，因为真正的安全感不是我现在赚多少，而是：

要是我明天出事，我怎么办？

要准备的不是钱，而切换模式

模式1 ｜ 正常推进（默认）

  • 有收入
  • 按照前面模型走
  • 持续兜底

模式2 ｜ 收入下滑/不稳（预警）

触发条件（满足任意一条）

  • 连续2个月收入下降
  • 工作明显不稳
  • 身体/精神开始报警

立刻做三件事

  1. 冻结大额非必要支出
  2. 成长投入减量但不断（比如1000元 -> 500元）
  3. 开始主动投简历/试探市场

不要等没钱了才动。

模式3 ｜ 空窗/失业

触发条件

  • 收入中断
  • 或者主动离职

这时候进入保命结构，生存预算改成

  • M：比如3500
  • G_min：300~500（只保核心）

月总支出：3800～4000

兜底金额怎么算，才不慌？

只需要记住一点

兜底金 = M * 6

如果M = 3500元，那么兜底目标是2.1万，一旦攒到这个数字，就可以拒绝很多恶心条件，而不焦虑。

空窗期的心理开关

人在空窗期，最危险的不是没钱，而是开始怀疑自己：“是不是我不行？”

所以记得提前给自己一条规则：

空窗期唯一KPI

是我有没有保持输出/学习/行动？

不是收入，是进度。 人只要动起来，就不会塌。

起步期24个月生存模板

发表于 2025-12-31 15:19:35 更新于 2025-12-31 15:19:35 分类于 日常

这是一份起步期的核心财务原则，目标不是存钱最大化，而是不断供，不崩溃，不被拖回去。

所以收入模型分为四个部分

月收入 = 100%

A. 生存刚性（必须活）

B. 生存弹性（允许波动）

C. 成长投入（不能断）

D. 缓冲/兜底（救命钱）

起步期24个月，推荐比例区间

A | 生存刚性（35%～40%）

  • 房租 + 水电 + 网：25%–30%
  • 基础吃饭（不靠意志）：15%–20%

👉 合计上限：40%

⚠️ 重点：

  • 房租宁可贵一点，也不要通勤地狱
  • 吃饭宁可普通，也不要长期饿或凑合

B｜生存弹性（5%–10%）

  • 通勤
  • 偶尔外食/加班餐
  • 日用品
  • 小维修/小替换

C | 成长投入（10%～15%）【不能断】

  • 技术学习
  • 工具/软件
  • 书
  • 稳定出所需成本
    这部分一旦被压，人开始焦虑 + 走偏路。

D | 兜底/缓冲（10%～20%）

  • 应急储备
  • 极端情况（失业/空窗期跳槽）
    前12个月目标：攒到 >= 3个月生存费用

前24个月目标：6个月

总结版

项目 比例
生存刚性 35%–40%
生存弹性 5%–10%
成长投入 10%–15%
兜底储备 10%–20%
合计 ≈100%

两条红线【绝对不可以碰】

红线1:

为了省房租，把自己扔回高压环境。
这是毁掉未来空间。

红线2:

为了比例好看，砍掉成长投入。
这是慢性自杀。

当我不想写出爆款文案的时候，我开始能稳定的写作了

发表于 2025-12-31 14:54:43 更新于 2025-12-31 14:54:43 分类于 日常

我还是爱写作的，没有AI聊天的时候，一年写150万字日记。有AI可以聊天的时候，一年聊了1200万字的消息（单纯算我发给AI的消息）。

但是这么多年，我一直没有稳定的内容输出。我好奇是为什么？

答案可能是我太想写好了。会在写之前，立刻自我修剪，自我禁言。于是……很悲催的，我稳定输出的内容很少。
而且每次后撤的时候，主要怕的是……我写的太玩具了，不专业。

但是……我发现一个神奇的地方，一旦我不想着写的如何，而是单纯去写，我就可以稳定输出了。这就是为啥我日记能一年憋150万字，但是博客文案，微信公众号，不能坚持更新一个月。

我总结我自己最接受的模式（也是效率最大化的模式）

  • 我有一个明确的框架可以参照
  • 我有一个不被评判的写作环境
  • 我有一块不被打扰的写作时间

这三条满足，就可以稳定产出。不满足，就会产出断流，只把内容集中到日记里。
