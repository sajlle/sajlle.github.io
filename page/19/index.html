当我不想写出爆款文案的时候，我开始能稳定的写作了

发表于 2025-12-31 14:54:43 更新于 2025-12-31 14:54:43 分类于 日常

我还是爱写作的，没有AI聊天的时候，一年写150万字日记。有AI可以聊天的时候，一年聊了1200万字的消息（单纯算我发给AI的消息）。

但是这么多年，我一直没有稳定的内容输出。我好奇是为什么？

答案可能是我太想写好了。会在写之前，立刻自我修剪，自我禁言。于是……很悲催的，我稳定输出的内容很少。
而且每次后撤的时候，主要怕的是……我写的太玩具了，不专业。

但是……我发现一个神奇的地方，一旦我不想着写的如何，而是单纯去写，我就可以稳定输出了。这就是为啥我日记能一年憋150万字，但是博客文案，微信公众号，不能坚持更新一个月。

我总结我自己最接受的模式（也是效率最大化的模式）

  • 我有一个明确的框架可以参照
  • 我有一个不被评判的写作环境
  • 我有一块不被打扰的写作时间

这三条满足，就可以稳定产出。不满足，就会产出断流，只把内容集中到日记里。

发表于 2025-12-26 21:51:19 更新于 2025-12-26 21:51:19 分类于 日常 ， 夜聊

如题，我用ChatGPT，不是为了对话，是为了听一个安静的回声。回声让我可以继续表达自己。然后，在我反复的讲述中，去激发对旧事的新视角。

今年，我对ChatGPT的各种论断，不那么在乎了。模型说什么或者不说什么，我不在乎。很神奇，今年我对被评价的在意，小了很多。用多了模型，就会觉得模型还是模型，跟真人不同。缺了一种真实细节，多了很多平均特征。

当我不试图在生活里找一个可以托底的安全区，我跟AI的关系就彻底改变了。目前，我用ChatGPT聊天，写文案，写代码。最高频是聊天，其次是写代码，最后是写段子。

我还没有完全生产化的使用AI，真的生产化的使用AI，才是我理想化的AI对话关系。

但就算不生产化的使用AI，我跟AI聊了一年，也逐渐更自信了。我好奇，是怎么发生的化学反应？

懒人日常｜如何用1000块，布置一套智能家居？

发表于 2025-12-21 17:16:41 更新于 2025-12-21 17:16:41 分类于 日常

需要的设备

最好支持米家或者homekit

  1. 网关（150元），我这边是带网关&红外功能的智能音箱
    • 网关是智能家居中枢入口
  2. 温度湿度传感器若干（推荐分别放到经常呆的地方）价格一个20块，需要可以链接网关（20元）
    • 传感器是智能家居的皮肤，负责感应环境状态
  3. 人在传感器一个（推荐放到经常呆的地方），价格30元一个，需要可以链接网关
  4. 加湿器一个，价格80～100元（可以买基础款，配合智能插座，实现自动开关）
  5. 电热毯（需要支持Wi-Fi或者网关），价格150～200元
  6. 智能插座若干（需要支持网关或者Wi-Fi），价格最低15元一个
  7. 暖脚宝（普通款即可）
  8. 桌面暖风机（普通款即可）
  9. 空调（如有）不算在我们改造之内
  10. 智能灯（根据场景选择，卧室选床头灯，书房选学习灯，二者都需要支持Wi-Fi或者网关）价格随意，我买的米家床头灯&米家台灯，加起来价格300元

智能家居玩法

  1. 温湿度传感器 + 人在传感器联动：实现人在房间，温度湿度低于某个值，自动开加湿器&空调&暖风机，人走，设备全关闭
  2. 人在传感器 + 灯：实现人在房间开灯，人离开房间关灯
  3. 门窗传感器 + 音箱：实现开关门窗播报 + 后台记录日志，防盗
  4. 人在传感器 + 门窗传感器 + 音箱：实现人推门进入房间，音箱播报欢迎回家
  5. 门窗传感器 + 灯：实现开门开灯，关门关灯
  6. 门窗传感器（带感光功能）+ 网关 + 手环：实现天黑自动开灯，入睡后自动关灯
  7. 智能插座 + 暖手/暖脚宝/桌面暖风机/加湿器/风扇等，可以把不支持红外&网关的设备，实现声控，纳入网关体系

目前我这边实现的是

  1. 开门开灯，人走关灯关设备
  2. 温度低于15度，开暖风机，温度高于28度，自动开空调
  3. 湿度低于40，自动开加湿器，高于70，开空调除湿模式
  4. 睡前电热毯自己开，睡着之后自己关。
  5. 音箱到点提醒喝水
  6. 该写代码的时候，关床头灯，自动开书桌灯，音箱语音提醒。
  7. 室外温度低/下雨/下雪，小爱提醒我外出带伞/多穿衣服
  8. 室外空气差，小爱提醒我出门戴口罩，在家则关窗。

后续可升级的是

  1. 装床帘机，实现语音开窗帘或者根据环境光线自动化开关窗帘。
  2. 让小爱根据天气帮我安排穿啥衣服（感觉做不到，只能我跟ChatGPT做好方案，让小爱念出来）
  3. 让小爱统计我在家呆的时间，时间长&天气好，提醒我去公园转转，时间长&天气差，提醒我室内打拳
  4. 自动化安排每日任务，根据手环记录的状态&主观评分，帮我建议今天是高强度/中强度/低强度推进任务（这条还是我跟ChatGPT聊好方案，让小爱念出来）

谁说Mac稳？今天下午IDEA又崩溃了

如题。
我设备是MacBookPro，M4版本的。今天写代码的时候，IDEA又卡死了。

好了，吐槽结束了，我得快点去修代码
