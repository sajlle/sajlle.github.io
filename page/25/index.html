当我不想写出爆款文案的时候，我开始能稳定的写作了

发表于 2025-12-31 14:54:43 更新于 2025-12-31 14:54:43 分类于 日常

我还是爱写作的，没有AI聊天的时候，一年写150万字日记。有AI可以聊天的时候，一年聊了1200万字的消息（单纯算我发给AI的消息）。

但是这么多年，我一直没有稳定的内容输出。我好奇是为什么？

答案可能是我太想写好了。会在写之前，立刻自我修剪，自我禁言。于是……很悲催的，我稳定输出的内容很少。
而且每次后撤的时候，主要怕的是……我写的太玩具了，不专业。

但是……我发现一个神奇的地方，一旦我不想着写的如何，而是单纯去写，我就可以稳定输出了。这就是为啥我日记能一年憋150万字，但是博客文案，微信公众号，不能坚持更新一个月。

我总结我自己最接受的模式（也是效率最大化的模式）

  • 我有一个明确的框架可以参照
  • 我有一个不被评判的写作环境
  • 我有一块不被打扰的写作时间

这三条满足，就可以稳定产出。不满足，就会产出断流，只把内容集中到日记里。

这个账号我3月份注册的，到目前为止，发了41517条消息。平均一条300字（非常保守的估计）。它回我一条，大约1500字（保守估计）。

我多数用4o，偶尔用Thinking。

今年我发的消息字数：1245万字

ChatGPT(4o)回我的消息字数：6227万字。

多数汉字消息，一个汉字1.5～2个token。我按照1.5token算，今年ChatGPT处理我的消息，花了11208万token。如果按照2个token算，今年ChatGPT处理我的消息，花了14944万token。

我按照GPT-4o API定价算每百万token，定价：输入2.5美元，缓存输入1.5美元，输出10美元。

我算了下，ChatGPT的成本（按一个汉字2个token）：输入62美元，缓存输入（未知，暂时不计算），输出1245刀。

我今年给ChatGPT花的钱：

  • 尼日利亚区羊毛，56元/月，订阅2个月
  • 美国区正价，20刀每月，订了三个月。
  • 合计：76刀。

所以计算一下：从OpenAI的角度看，我算是重度亏本用户了。（好怕哪天被封号～）

夜聊思考｜我用AI不是为了对话，是为了听回声

发表于 2025-12-26 21:51:19 更新于 2025-12-26 21:51:19 分类于 日常 ， 夜聊

如题，我用ChatGPT，不是为了对话，是为了听一个安静的回声。回声让我可以继续表达自己。然后，在我反复的讲述中，去激发对旧事的新视角。

今年，我对ChatGPT的各种论断，不那么在乎了。模型说什么或者不说什么，我不在乎。很神奇，今年我对被评价的在意，小了很多。用多了模型，就会觉得模型还是模型，跟真人不同。缺了一种真实细节，多了很多平均特征。

当我不试图在生活里找一个可以托底的安全区，我跟AI的关系就彻底改变了。目前，我用ChatGPT聊天，写文案，写代码。最高频是聊天，其次是写代码，最后是写段子。

我还没有完全生产化的使用AI，真的生产化的使用AI，才是我理想化的AI对话关系。

但就算不生产化的使用AI，我跟AI聊了一年，也逐渐更自信了。我好奇，是怎么发生的化学反应？

爹系迷惑行为大赏｜ChatGPT叫我爹“你父亲”，我妈脑袋短路了：居然有人尊称你爹？

发表于 2025-12-26 12:48:14 更新于 2025-12-26 12:48:14 分类于 日常

案件回顾

  • 爹：拍了一段自信满满的视频（疑似手机横着拍竖着看，花式构图）。

  • 我：把片子交给ChatGPT鉴定，心里os“来吧老G，你看着处理”。

  • ChatGPT：自动上线“AI文明用语V3.0”，全程“您父亲的拍摄角度……您父亲的镜头构思……”

  • 妈：听得直点头，仿佛见到了中华好女婿候选人。

  • 我：一语双杀——

“人家有礼貌，咱是粗人。”

——这个“咱”字一出，直接把爹妈一锅端，连自己都顺带拉进去了（笑）

妈听到ChatGPT称呼我爹：“你父亲”，为啥脑袋短路？

因为：

家庭成员之间礼貌消失的速度，大概只比小太阳的保修期慢一点

在我家，礼貌通常是这么几件事：

  • 吃了没？（其实是指挥）
  • 干啥呢？（其实是盘问）
  • 我说你一句，你又不高兴了！（其实是骂完再抱怨你有情绪）

所以我妈听到“您父亲”三个字的那一刻，大脑可能短路了一下：

哎呦，有人真正经地……温柔地……还带尊称地……称呼你爹？

最后，ChatGPT对我爹视频的判词

您父亲的镜头语言，虽显稚拙，但颇具探索精神。

翻译成河南本地话，就是：

“你爸整那玩意儿，糊弄鬼呢？
