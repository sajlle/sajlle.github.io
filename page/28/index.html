懒人日常｜如何用1000块，布置一套智能家居？

发表于 2025-12-21 17:16:41 更新于 2025-12-21 17:16:41 分类于 日常

需要的设备

最好支持米家或者homekit

  1. 网关（150元），我这边是带网关&红外功能的智能音箱
    • 网关是智能家居中枢入口
  2. 温度湿度传感器若干（推荐分别放到经常呆的地方）价格一个20块，需要可以链接网关（20元）
    • 传感器是智能家居的皮肤，负责感应环境状态
  3. 人在传感器一个（推荐放到经常呆的地方），价格30元一个，需要可以链接网关
  4. 加湿器一个，价格80～100元（可以买基础款，配合智能插座，实现自动开关）
  5. 电热毯（需要支持Wi-Fi或者网关），价格150～200元
  6. 智能插座若干（需要支持网关或者Wi-Fi），价格最低15元一个
  7. 暖脚宝（普通款即可）
  8. 桌面暖风机（普通款即可）
  9. 空调（如有）不算在我们改造之内
  10. 智能灯（根据场景选择，卧室选床头灯，书房选学习灯，二者都需要支持Wi-Fi或者网关）价格随意，我买的米家床头灯&米家台灯，加起来价格300元

智能家居玩法

  1. 温湿度传感器 + 人在传感器联动：实现人在房间，温度湿度低于某个值，自动开加湿器&空调&暖风机，人走，设备全关闭
  2. 人在传感器 + 灯：实现人在房间开灯，人离开房间关灯
  3. 门窗传感器 + 音箱：实现开关门窗播报 + 后台记录日志，防盗
  4. 人在传感器 + 门窗传感器 + 音箱：实现人推门进入房间，音箱播报欢迎回家
  5. 门窗传感器 + 灯：实现开门开灯，关门关灯
  6. 门窗传感器（带感光功能）+ 网关 + 手环：实现天黑自动开灯，入睡后自动关灯
  7. 智能插座 + 暖手/暖脚宝/桌面暖风机/加湿器/风扇等，可以把不支持红外&网关的设备，实现声控，纳入网关体系

目前我这边实现的是

  1. 开门开灯，人走关灯关设备
  2. 温度低于15度，开暖风机，温度高于28度，自动开空调
  3. 湿度低于40，自动开加湿器，高于70，开空调除湿模式
  4. 睡前电热毯自己开，睡着之后自己关。
  5. 音箱到点提醒喝水
  6. 该写代码的时候，关床头灯，自动开书桌灯，音箱语音提醒。
  7. 室外温度低/下雨/下雪，小爱提醒我外出带伞/多穿衣服
  8. 室外空气差，小爱提醒我出门戴口罩，在家则关窗。

后续可升级的是

  1. 装床帘机，实现语音开窗帘或者根据环境光线自动化开关窗帘。
  2. 让小爱根据天气帮我安排穿啥衣服（感觉做不到，只能我跟ChatGPT做好方案，让小爱念出来）
  3. 让小爱统计我在家呆的时间，时间长&天气好，提醒我去公园转转，时间长&天气差，提醒我室内打拳
  4. 自动化安排每日任务，根据手环记录的状态&主观评分，帮我建议今天是高强度/中强度/低强度推进任务（这条还是我跟ChatGPT聊好方案，让小爱念出来）

学习路线｜AI大模型入门指南（实操版）

发表于 2025-12-21 08:54:44 更新于 2025-12-21 08:54:44 分类于 学习指南

目标

6周快速入门AI大模型，这个指南面向实操，非空谈理论。
用「看得懂的数学 + 跑得起来的模型」快速让你理解 AI 是怎么工作的，不是让你变成科学家，而是变成“能复刻、能应用、能理解原理的AI使用者”。

这门课的逻辑：“先靠视觉直觉建立底层感，再以实操拉通模型，最后用名校体系和访谈扩维。”

6周课程一览表

阶段 目标 核心内容 可加内容
第1周 打基础 3B1B + StatQuest 加上 Python Numpy 实操
第2周 跑通模型 fast.ai 开篇 加 MNIST/CIFAR 小项目
第3周 理解架构 Karpathy “nanoGPT” 学一点《Dive into Deep Learning》配合
第4周 工程与评测 Dave + Hamel 加实验记录 + prompt评测
第5周 系统补课 CS229 + Serrano 整理公式卡片
第6周 视野拓展 MLST + Lex 每周一篇长谈笔记

课程原理

它不像大学四年慢慢教你基础，也不像培训班拿案例让你抄作业，而是：

第1步：先用直觉和图像理解数学 → 不恐惧它

第2步：写几行代码跑个模型 → 感觉AI不是高不可攀

第3步：系统学习理论 → 建立长效认知

第4步：接入实战项目 → 和真实场景接轨

学习方式

推荐使用的「双速笔记法」：

每看一个视频，写两行：

  • 直觉行：这个概念的 比喻/图像/操作感受（你自己说出来）

  • 公式/代码行：这背后涉及的公式/结构/代码框架

举例：

看完“逻辑回归”这节视频

直觉：像是在找一条“让正负例分开最开”的线，但用的是概率表示。

公式：y = sigmoid(w·x + b)，损失函数是交叉熵。

每周看两个视频，复刻一个模型，写一篇“AI周记”。

这是我的互联网白蹭指南。

课程篇

目标：不花钱白蹭互联网上名校名师课程（笑）

中国大学Mooc

强烈推荐的几门课：

  • 北京大学的行为经济学
  • 上海外国语大学的法语初级（嗯，视频跟线下课堂内容一样，这是最大推荐理由，但实际纯线上上课效果如何？我也不清楚。只是线下录这个mooc的时候，我在线下上过，发现视频内容跟线下课内容没大区别）
    强烈不推荐的几门课：
  • 计算机相关
    • 几乎找不到系统的课程
    • 很多偏入门
    • 系统&面向就业，还是看培训班的课程吧
    • 补充理论，去看MIT，伯克利开的课程吧
    • 算法相关（纯解题），请看卡哥的代码随想录
  • 外语相关
    • 线下课程没有纠音
    • 基本无法凑齐系统课程
    • 如果只是要冷启动，不如多邻国可以碎片化刷
    • 如果要系统学习，不如培训机构课程系统
    • 属于趣味性不高，而且系统性不足的尴尬位置

CS自学指南

强烈推荐的几门课（只推我上过的）：

  • CS61A
    • 伯克利开的课，面向没有CS基础的本科生
    • 不是只讲理论，HW,Project，Lab，有很多小项目，很有趣
    • 讲课老师风格幽默，不枯燥
  • MIT：The Missing Semester …
    • 补全了UNIX工具使用
    • 纯工具课程
    • 有中文课件

强烈不推荐的几门课

  • 哈佛的CS50X
    • 过于简单，虽然开给小白，但绕了八百圈，如果小白，还是推荐CS61A，信息密度更高一些。
    • 因为过度简单，所以学完没啥成就感

B站上的培训班公开课

强烈推荐的几门（我自己上过）

Angela Yu的前端课

  • 适合纯小白
  • 一节课一个小项目，轻松完成
  • 短，适合碎片化学习
  • 废话少，没有低俗梗

培训班的项目实战课

  • 真上项目
  • 公开展示的课质量更高一些（虽然也有很多错误）
  • 缺点：
    • 讲师爱讲低俗黄色梗
    • 啰里八嗦废话多
    • 一讲就是30分钟，没时间写代码
  • 怎么学效率最高：
    • 有基础的话：不看课程，直接看课程笔记&文档，自己跑一遍，跑不通的，工具不会用的，看两眼课程
    • 没基础的话：不建议看这种动辄几百集的项目培训课，废话多，效率低，浪费时间
    • 和AI合作：
      • 培训班项目提供架构
      • 细节自己实现
      • 工具不会问AI
      • 自己写完细节跟培训班的写法对比一下

极度不推荐的几门课（我真踩过坑）

  • 培训班的基础入门课（废话多，多操作&演示，原理不深入）
    • 不如直接看国外大学开的基础课
      • 数据结构看CS61A
      • 算法看CS61B

数学

虽然我有几门课想推荐，但只写我学过的吧，其他还没学的，就不放了
强烈推荐：

3B1B的线性代数

  • 形象化，好理解，不抽象
