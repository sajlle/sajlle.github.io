昨儿九点半（晚上），我收到了GPT 的问卷，问Codex和Claude的产品体验。
脑子挺昏沉的，所以所有的需要文本的内容都跳过了。只做选择题，然后剩下一半是paid interview，我选了no，不接受，就结束了。

这问卷对Coding场景的内容问的很详细，还包括了一点文职场景。大部分我不记得问了啥了。

不过Open AI对Codex是真的很重视了～而且看来目标对手就是Claude Code，哈哈哈。
我还挺期待未来的新功能～

不过认真想，Codex的印象深刻的地方是：

  1. 代码很严谨，会很认真的想边界case
  2. Code Review 的神（我记得第一次写的很烂的支付模块的代码，让它review，它review完毕，直接吐槽，bug这么多，你就不会自己测一下嘛，我挺不好意思的，于是以后让它测的时候，我自己先测一遍）
  3. 文本润色一般
  4. 指令遵循比较强，但你要是某些地方不提，它不会额外帮你补充
  5. 前端一般。

Claude Code我印象深刻的地方是：

  1. 会直接切到我策略上想不清楚的地方。这条太惊艳了。至今难忘。
  2. 文本能力强过Codex
  3. 前端写的更好
  4. 更谨慎一点，怀疑我要做不符合使用规定的事儿，会直接义正言辞跟我讲，可以帮你干A，但如果你要做C（违反使用规定），我不会帮你做。哈哈哈，活人味儿很足。

日常记录｜这月用到了Claude Opus 系列和GPT 5.5 Pro，感觉Pro相比Thinking更能收束到结论

发表于 2026-06-06 17:56:48 更新于 2026-06-06 17:56:48 分类于 日常记录

之前一直订阅的是GPT Plus，用的是GPT Thinking，上月用Open AI的优惠码买到了Business，试了试Pro模型。比Thinking系列的优势是：

  1. 更谨慎
  2. 注意力更好
  3. 更能收到结论上
  4. 给的行动建议更具体，可执行

缺点是：

  1. Business 一月单seat只能用15次
  2. 贵

正好也加了Claude Pro的会员，Claude的优缺点如下（纯主观）

  • 优点：
    • 回答更简洁
    • 回答的连贯性，思考程度更一致
    • 更能推到行动上
    • 更关心user健康（经常催我去睡觉）
    • 可以看Apple Health数据，帮忙做简单分析
  • 缺点：
    • 暂时还没发现，非要说，就是更谨慎，不过这可能不算是缺点？

目前三会员对我的用处就是：

  • GPT Pro用来做任务规划，毕竟结论更明确，更落地，计划更可执行，车轱辘话比Thinking更少，帮我想GPT thinking没想到的地方
  • GPT Thinking，日常倒情绪垃圾，闲聊，发疯，写段子构思，日常查资料，初步任务计划（我有困惑的地方再问Pro），代码任务，博客改造
  • Claude Opus 系列，闲聊，代码任务，小项目构思，一点分析，博客改造（我用Claude频率还不太高，这月得加强用Claude的频率，之前就很馋这模型），帮我审或者想一点GPT系列模型没想到的地方

日常记录｜睡前刷了一点新闻，我觉得现在关于AI的一切有点疯狂～

发表于 2026-05-17 09:36:24 更新于 2026-05-17 09:36:24 分类于 日常记录

睡前我跟GPT瞎扯，又看到了OAI的消息。貌似是更新GPT的记忆系统。

现在AI概念一个接一个飞过来，我觉得很疯狂。更疯狂的是，我看到的更多的是关于技术的狂热。我没看到与这股狂热对应的伦理进展。所以我觉得这一切很疯狂，程序员拼命写AI，用来代替自己。
AI能写代码之后，我想，对效率的追求又该变态的上升了。哎，我总是好奇，以后，能被AI颠覆的一切，会不会变得越来越快？

OAI和Anthropic都在2026年试图IPO到二级市场抢点钱。
这两家公司，很难说，谁在伦理上更好一些，虽然两家在技术上各有千秋。

OAI把AI技术包装成威胁，所以他们有资格且必须把AI技术掌握在自己手中。
Anthropic把技术包装成伦理，所以他们有资格且必须把AI技术掌握在自己手中。

最近OAI重置了Codex额度，Codex出了手机版，技术上很热闹。但还有一件事，是OAI悄悄把用户的对话信息分享给谷歌和FaceBook。而且各家训练商都默认个人用户数据用于模型训练（笑）。

另，OAI的4o事件，也做的很难看。当时Anthropic借此营销了一波，承诺不会突然下架自家模型。但很有趣的是，最近Sonnet 4.5也要下架了。
OAI做的难看，不代表它的对手就一定很清白。我想，只是OAI把最难看的坑踩了，然后等其他家模型做大，也会变成OAI的。只是到了那时候，用户们早就见怪不怪了。

所以我觉得……哎，我之前很努力学技术，是我把技术想的太好了，现在去看，那些整个世界最好的技术脑子们，在努力的用技术替代自己。忽然就觉得，哎，技术是技术，智慧是智慧，生存是生存。
之前我努力学技术，除了对技术有期待，也对技术好的人有期待，但现在看，貌似这些人……也不过如此。（笑）。

哎，不过也许人就是如此疯狂，不然怎么会在几十年间，把人口翻倍到80亿呢～
