日常记录｜最近住妈爹家，我感觉被霸凌了哈哈～

趁着Codex在审核代码，我来写写最近的细节。

之前我心率/血糖/血压都高的时候，妈爹第一时间不是问我身体，而是托亲戚问我：「你啥时候能上班～」。也就是上月的事儿了。

然后二位觉得我不能工作了，立刻开始玩霸凌游戏，我爹不洗碗，然后第二天说，是我不洗碗。我懒得吵架。
我妈天天找茬，讲，你不运动。我打拳击+散步跑路，一天跑5公里，还不运动？我拿Apple Watch给她看，她立刻换话题攻击。

今天又是我在写代码，我妈：「你碗没洗～」。
我：「不让你洗，能安静一下吗？我写代码呢」
她：「你接到活儿啦？」
我：「你先安静，我写完这段～」

哎，不提供帮助就罢了，天天把焦虑倒灌给我，然后揪着鸡毛蒜皮的事儿不停放大，上升到人身攻击，这也太离谱了吧。本来这几天我忍着不打算写呢，天呐，住他们一个6平米的不通风卧室，就是天大的恩赐了，觉得我占了他们天大的便宜（笑）。
不过联想到他们让我7岁开始就物尽其用，干童工到19岁，作出这种事情也是不让人惊讶了。呵呵。

另，期间还有一件事，我妈找我弟要500块。我弟不想给，于是说：「你自己拿好这钱，别让老瑞给你转走，老瑞在家别让她闲着，让她给你们干活儿换钱」
于是当天我删除了我弟的所有联系方式，嗯，我从此以后不认识这人。

本来生病他没有半句关心也就罢了，直接落井下石，把我想成小偷+懒鬼，那就过分的很了。
不过联想到他本人在2022年我花钱给他买了东西之后，说这东西他买了，因此我们吵架，他持刀追砍我的事儿发生之后，这人后续的行为也不让人惊讶了。

嗯，我家的逻辑一以贯之，哈哈，把儿子养成废物，把女儿用成残废。
嗯，我弟去年外出三个月，去云南，谈了一个学生女友，三个月自己没挣钱，倒是欠了学生女友一万多。嗯，社会人欠学生钱，说出去我都觉得丢脸。今年这钱他还了人家没，我不知道，也懒得知道。
哎，这叫什么呢？这叫从根子上就烂了，后续怎么修也无用。

日常记录｜昨晚收到Open AI的问卷，问Codex和Claude Code的使用体验的，我试着答了一下

发表于 2026-06-07 13:06:19 更新于 2026-06-07 13:06:19 分类于 日常记录

昨儿九点半（晚上），我收到了GPT 的问卷，问Codex和Claude的产品体验。
脑子挺昏沉的，所以所有的需要文本的内容都跳过了。只做选择题，然后剩下一半是paid interview，我选了no，不接受，就结束了。

这问卷对Coding场景的内容问的很详细，还包括了一点文职场景。大部分我不记得问了啥了。

不过Open AI对Codex是真的很重视了～而且看来目标对手就是Claude Code，哈哈哈。
我还挺期待未来的新功能～

不过认真想，Codex的印象深刻的地方是：

  1. 代码很严谨，会很认真的想边界case
  2. Code Review 的神（我记得第一次写的很烂的支付模块的代码，让它review，它review完毕，直接吐槽，bug这么多，你就不会自己测一下嘛，我挺不好意思的，于是以后让它测的时候，我自己先测一遍）
  3. 文本润色一般
  4. 指令遵循比较强，但你要是某些地方不提，它不会额外帮你补充
  5. 前端一般。

Claude Code我印象深刻的地方是：

  1. 会直接切到我策略上想不清楚的地方。这条太惊艳了。至今难忘。
  2. 文本能力强过Codex
  3. 前端写的更好
  4. 更谨慎一点，怀疑我要做不符合使用规定的事儿，会直接义正言辞跟我讲，可以帮你干A，但如果你要做C（违反使用规定），我不会帮你做。哈哈哈，活人味儿很足。

日常记录｜我应该是国内比较早玩GPT的一批人了～

发表于 2026-06-07 11:31:00 更新于 2026-06-07 11:31:00 分类于 日常记录

2022年11月GPT发布，我当然很感兴趣，但是没办法玩，（需要外币卡，外国手机号，我当时没有）。但是这好东西我怎么能不玩上？于是当年12月我就玩上GPT了，当然玩的中转站。
我问GPT第一个问题是：Alicia是一个工程师，请你用英雄之旅的模式，帮我写一个工程师拯救世界的故事。GPT给我写了一个故事弧线，从此我的某个平台用户名，就叫Alicia了。

然后接着我去做文案了，2023年，我试试用AI做文案，效果很差，除非你把文案拆成非常细腻的公式，它能写一个70分的文案。然后你还要人工加点料。

2024年，我用AI写代码demo，解释算法题。很多是Java的，用的是New Bing，也是这一年我从New Bing改成GPT。
这一年，我跟AI聊过的内容很多，有列维纳斯，Mylene Farmer，外语学习和口语练习，海外规划，代码（Python和Java）。

2025年，AI的能力提升了，我开始玩AI语言镜像能力测试，让不同AI做语言风格侧写。同时我开始玩AI Agent，我第一个Agent是Gemini Cli（因为它免费）。第二个是Github Copilot，第三个是Cursor，社区推荐它，我怕落伍，试了试，但我找它读我项目上下文的时候，它居然卡死了，从此出局。
随后就是Codex，它是包含在我的GPT Plus订阅里的，Codex帮我做Code Review很好用，梳理项目的主链路，事务边界，很好用。

2026年，我加了Claude Pro订阅，我现在固定用的Agent就是Codex和Claude Code。
主要就是写代码。架构之前我塞给GPT，我写，Codex Review，我能拿准自己会写的，就让Codex一起写了。架构现在塞给Claude Code，前端也塞给Claude Code，文案我还是偏向Claude Code。
其他杂七杂八的用法：

  1. 让Agent帮我发发博客，整理一下对话里的点子列一下。
  2. 做超级小娱乐项目，比如桌面宠物。
  3. 整理文件夹
  4. 做Anki卡
  5. 做Excel表（虽然我不经常用了）
  6. 写文档（接口文档，测试文档，简单文案初级版本，简历等等）。
  7. 其他脑抽的小点子出来，让它们帮我干一版MVP

昨儿我问GPT，Codex和Claude Code用户多吗？它说，Codex周活500万，Claude月活5600万（带聊天和Code一起）。我感觉我算是玩AI比较早的人了。
我很惊讶的是，社交媒体上很多人在晒AI Agent，但现实里貌似真玩这个的不多？Agent用户比较多的是Coding用户，虽然现在很多知识工作者也开始用Agent干活儿了。
但比例依然是很小。

同时，我跟GPT聊，现在国内文职用AI的场景，然后发现目前国内文职场景里用AI的地方，跟三年前没啥区别，还是写文案，做报表，文本润色，继承到Office类的软件里。

最后，我发现，只要靠近我喜欢的东西，被欲望驱逐着走（我的欲望是「这东西好玩，我要试试」），就能不知不觉跑到很靠前的位置。
