日常记录｜我应该是国内比较早玩GPT的一批人了～

发表于 2026-06-07 11:31:00 更新于 2026-06-07 11:31:00 分类于 日常记录

2022年11月GPT发布，我当然很感兴趣，但是没办法玩，（需要外币卡，外国手机号，我当时没有）。但是这好东西我怎么能不玩上？于是当年12月我就玩上GPT了，当然玩的中转站。
我问GPT第一个问题是：Alicia是一个工程师，请你用英雄之旅的模式，帮我写一个工程师拯救世界的故事。GPT给我写了一个故事弧线，从此我的某个平台用户名，就叫Alicia了。

然后接着我去做文案了，2023年，我试试用AI做文案，效果很差，除非你把文案拆成非常细腻的公式，它能写一个70分的文案。然后你还要人工加点料。

2024年，我用AI写代码demo，解释算法题。很多是Java的，用的是New Bing，也是这一年我从New Bing改成GPT。
这一年，我跟AI聊过的内容很多，有列维纳斯，Mylene Farmer，外语学习和口语练习，海外规划，代码（Python和Java）。

2025年，AI的能力提升了，我开始玩AI语言镜像能力测试，让不同AI做语言风格侧写。同时我开始玩AI Agent，我第一个Agent是Gemini Cli（因为它免费）。第二个是Github Copilot，第三个是Cursor，社区推荐它，我怕落伍，试了试，但我找它读我项目上下文的时候，它居然卡死了，从此出局。
随后就是Codex，它是包含在我的GPT Plus订阅里的，Codex帮我做Code Review很好用，梳理项目的主链路，事务边界，很好用。

2026年，我加了Claude Pro订阅，我现在固定用的Agent就是Codex和Claude Code。
主要就是写代码。架构之前我塞给GPT，我写，Codex Review，我能拿准自己会写的，就让Codex一起写了。架构现在塞给Claude Code，前端也塞给Claude Code，文案我还是偏向Claude Code。
其他杂七杂八的用法：

  1. 让Agent帮我发发博客，整理一下对话里的点子列一下。
  2. 做超级小娱乐项目，比如桌面宠物。
  3. 整理文件夹
  4. 做Anki卡
  5. 做Excel表（虽然我不经常用了）
  6. 写文档（接口文档，测试文档，简单文案初级版本，简历等等）。
  7. 其他脑抽的小点子出来，让它们帮我干一版MVP

昨儿我问GPT，Codex和Claude Code用户多吗？它说，Codex周活500万，Claude月活5600万（带聊天和Code一起）。我感觉我算是玩AI比较早的人了。
我很惊讶的是，社交媒体上很多人在晒AI Agent，但现实里貌似真玩这个的不多？Agent用户比较多的是Coding用户，虽然现在很多知识工作者也开始用Agent干活儿了。
但比例依然是很小。

同时，我跟GPT聊，现在国内文职用AI的场景，然后发现目前国内文职场景里用AI的地方，跟三年前没啥区别，还是写文案，做报表，文本润色，继承到Office类的软件里。

最后，我发现，只要靠近我喜欢的东西，被欲望驱逐着走（我的欲望是「这东西好玩，我要试试」），就能不知不觉跑到很靠前的位置。

日常记录｜新到手的血糖仪，马上拆开试试

发表于 2026-06-07 09:38:56 更新于 2026-06-07 09:38:56 分类于 日常记录

前几天买的Roche的血糖仪到手了，今儿早上花了很久拆包开始扎手指。说几个我印象深刻的点：

  1. 试纸条带电级，有电级的那头插入，血糖仪会激活。之前去医院测血糖，没注意到这个。不过我是家用血糖仪，跟医院的不一样。
  2. 采血笔确实不疼，大概是跟被幼年态蚊子咬一口的感觉差不多，出血比较多。
  3. 家用版针头有盖子，扎完盖上扔垃圾的时候不容易伤到其他人。

其他搞笑版本的印象：

  1. 说明书是真的很长
  2. 除了说明书，还塞了一点血糖管理小册子（印象分++）
  3. Roche家用血糖仪系列，不仅想做产品，还想做用户运营，他们有专门的小程序，还搞了社群。我去看了下，有点像是血糖版本的小红书打卡+日常分享。只是塞到微信小程序里了。哎，很可以，很有想法。比只卖仪器强多了。但是有个问题，这社区需要手机号注册才能用全部功能，我有点好奇，血糖这类健康数据，隐私性很强，真的手机号注册，我还是有点抗拒的。但只网络注册，还好。
  4. 小程序有仪表盘，可以看每月的数据汇总。（这条很好）
  5. 仪器本身可以存储几百组数据，可以看历史数据，可以导入历史数据（但导入数据这条，老中这边不支持）
  6. 采血笔说明书上说用了弹道推进原理。嗯，莫名好奇，是不是速度快到让你注意不到疼，就不会疼？速度快+转移注意力，痛感会大大减少？那采血笔摁下去的时候，再加个双闪+音效，效果会不会更好？哈哈哈，感觉这样玩下去，扎手指就变成了一种很奇怪的行为艺术了。
  7. 血糖仪不贵，后续试纸是长期消耗品。所以套机不贵。
  8. 总体印象：这公司很聪明，知道血糖管理不只是仪器，试纸，还有信息筛选，睡眠管理，生活习惯管理，而且在做后面几种生意了。我觉得仪器可以换别家的，但后面的生活管理，信息摄取习惯了这家公司，那就不容易跑路到别家了。

最后，咋选的Roche的呢？
我是先跑路拼多多，淘宝，看血糖仪（家用），找几个高销售量的，看一下。看完之后有个大概的印象，当然主要看差评。然后到SNS评论区找。最后有人推荐，讲，医院那边用的多的是：「罗氏」「拜耳」「雅培」之类的。我就对比了一下罗氏和拜耳的，最后决定买罗氏的，理由简单：

  1. 套机价格差不多，但罗氏的试纸更便宜，血糖仪后续消耗最多的是试纸和针头。
  2. 拜耳这边找不到官方的旗舰店（或者我没办法确定这就是官方渠道），所以不敢买，罗氏这边微信公众号上写明白了官方渠道和授权渠道有哪些。所以买着比较放心一点。
  3. 罗氏的正好有国家补贴，用国补买更便宜。

其实我之前买的时候，一开始是打算买鱼跃或者可孚的，毕竟这俩是国产家用健康品牌里比较有名的。不过被劝退的理由是：有人在电商评论区说某个型号的结果不准确，所以我就放弃了。
然后又知道了很多其他的没听过的品牌，比如三诺，风评不错，而且价格也OK，然后刷哔哩哔哩，评论区讲这家营销多，水军多，我仔细看了下，确实有几个评论不是同一个头像，但内容是一样的。于是也放弃了。
然后某个医生UP推荐罗氏和拜耳，于是我就打算买罗氏了。

日常记录｜SNS上火的低价区开海外AI会员，我来写写套路

发表于 2026-06-06 20:48:55 更新于 2026-06-06 20:48:55 分类于 日常记录

海外AI御三家（GPT,Claude,Gemini）的低价区会员，很多都是利用了App Store的全球分级定价体系。
举个例子，同样GPT会员，在美国区是20刀，在土耳其区，就是10刀左右。
这就是所谓的低价区羊毛（当然还是走的官方支付渠道，灰产那就另说）。

要走低价区，需要三个东西：

  1. iPhone
  2. 低价区Apple ID
  3. 海外支付渠道（比如买土耳其区的app store产品，就需要土耳其区本地的支付方式，其他区类似）

搞定之后，就可以跨区省点小钱。
不过做好心理准备，低价区未必持久，去年ChatGPT Plus尼日利亚区价格低到五十多RMB就能买到手，于是过了俩仨月，官方就把尼日利亚区的价格提的比美国区还高了。

当然，低价区这么省钱，我自己用的是哪个？我是美国区。理由是：

  1. 美国区经常有首发的beta功能。比如，去年ChatGPT的圣诞视频，还有年终总结，都是美国区抢先体验。Claude的读取Apple Health数据功能，也是美国区才有的beta功能。
  2. 美国区比低价区稳定，不需要反复折腾账号和支付方式。低价区如果跨区套利严重，会被提价，需要不停的折腾账号归属，支付方式。
  3. 美国区梯子节点多，稳定。某些低价区梯子节点也不大好找。

日常记录｜上月薅羊毛了英国区的Open AI Business 会员，我来写写怎么做的

发表于 2026-06-06 18:43:41 更新于 2026-06-06 18:43:41 分类于 日常记录

上月推特火了Open AI的Business 优惠，价格各种各样，其中英国区最低，11.5磅 2个席位。比官方的单Plus会员还便宜。我挺早就好奇GPT Pro， 但是Pro价格是200刀（1600元）一个月，挺贵。Business会员是20刀一个月，但必须俩人开，所以之前也不想开，（不想找陌生人组队）。

正好刷sns，看到美国区优惠20刀 2个席位，但没抢到。结果第二天看到英国区优惠，11.5磅（实际我是13磅，因为扣了税）。比GPT Plus单会员还便宜。于是立刻跟着教程来开会员。从10点半到14点半，折腾了四个小时。

找到优惠链接，点开，打开开发者工具，点进控制台，生成Stripe长链接，用一张海外卡支付。

这里面比较难的是，弄一张海外卡。我用的是ByBit。申请比较容易，开梯子，过KYC，然后开卡。开卡之后，通过欧易或者币安买币提到卡上，等扣款就行。链我用的Tron，需要1.5刀的手续费。

然后是扣款，分2步，第一步，授权，授权成功不代表交易成功。等ByBit显示交易成功，才是真的成功了。

最后折算下来，总共花了18.5刀（包括Tron的手续费，Business会员费，税费）。比Plus20刀单人还便宜，还多了30次Pro使用权。

这优惠是48个月，不是短期优惠，是oai开给各地合作伙伴的。需要特定的优惠链接才能开。除了英国区，还有澳洲区（25澳币 2个席位），美国区（20刀 两个席位）。
