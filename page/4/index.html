日常记录｜我学计算机进步最快的时候，是我抓着 AI 问废话的时候

发表于 2026-06-27 09:50:47 更新于 2026-06-27 13:27:33 分类于 日常记录

其实，AI 并没有自动抹平能力差距，但它显著降低了非科班、非名校、非大厂实习背景的人接触工程隐性知识的门槛。

培训班和AI的差别是？
培训班是：先讲概念 → 跟敲代码 → 项目跑通。
AI是：我现在要改这个业务 → 遇到具体问题 → 追问原因 → 修改 → 跑通 → 再抽象成理解。

培训班和AI的教学效率？

  • 培训班时期，我用六七个月，只学会了抄代码。
  • 用AI的时候，2个月从一窍不通到能写支付模块。

培训班的时期，我无法获得真实的工程经验。
但如今，我能靠着AI，在遇到真实问题的时候，获取藏在项目组，公司经验，师徒关系里的隐性知识。

培训班给我的是跑通的代码，AI给我的是追问的机会。
而我本来的优势不是获取信息差，而是处理信息、拆问题、反复追问、把散乱东西组织成理解。
正好，AI时代，会奖励这些能力。

社会观察｜中部县域家庭的教育资源幻觉与落点追踪

发表于 2026-06-26 10:37:04 更新于 2026-06-26 11:32:56 分类于 社会观察

没有书房的家庭，是最早被刷下来的

一、书房的缺席：孩子从未真正“有资格”读书

走进这些家庭的房子，会发现一种奇怪的对比：

  • 房间宽敞，楼层高，装修气派；
  • 但孩子没有独立书桌，写作业常常在杂物台或饭桌旁；
  • 多功能小桌承载了“吃饭+写作业+堆杂物”的三合一角色。

书房的缺席，不是空间不够，而是意识缺位。他们从来没在心理上真正为“学习”腾出专属位置。

在这些家庭的结构里，读书只是“社会命题的一项必填项”，但并非真正的“命运逆转工程”。它没有独立空间，也没有长期预算，只有临时应付。

二、家长很努力，但努力错了方向

你不能说这些家长不负责。他们真的盯得很紧：

  • 一边上班一边盯孩子写作业；
  • 给孩子买教辅资料（尽管孩子从不翻第二页）；
  • 甚至晚上熬夜陪背书，自己眼圈黑了还继续鼓励孩子。

但孩子的问题是根上的：

  • 阅读量极低，语言理解能力严重不足；
  • 作业只是“格式完成”，没有输入、思考、转化；
  • 学习习惯极差，必须靠人力驱动才肯启动；
  • 逻辑思维与自驱力几乎为零。

这些努力是用“纯人力”在拖动一辆没有发动机的车。

三、“总有一天会开窍”：幻想型麻醉逻辑

这是在中原最常听到的咒语：

“现在不爱学，等上了初中/高中就开窍了。”

这其实是一种家长自我安抚的话术。他们隐约知道孩子学不进去，但又不敢正面承认，于是将希望投注于：

  • 孩子突然觉醒；
  • 一次次模拟考能奇迹逆转；
  • 或者“别人家的孩子都差不多”，我家也不会太差。

“开窍神话”就像一剂止痛药，短期缓解焦虑，长期造成更大的损失。

而他们对真正的升学路径毫无概念——比如，985不是“想读就能读”的：

  • 小学要稳定前五，
  • 初中要年级前十，
  • 高中要实验班 + 年级前二十，
  • 每一段都是层层刷人、代价血淋淋。

可惜这些话，一说出来就显得“冷血”。必须附上真实案例，他们才略感动摇。

四、家长教育投资认知：全靠“梦境对号入座”

给他们讲OpenAI、讲AI公司，他们第一反应不是“怎么努力”，而是：

“我孩子能不能去？”

你一说：“要懂英语、会数学、能自学编程。”
他们立刻冷静：

“哦，那不行。”

这是一种非常典型的“情绪对号式资源误判”：

  • 感受到外界热度，就把孩子塞进去幻想；
  • 一旦碰到真实门槛，就立刻收手，然后等下次热潮再来幻想一遍。

他们从未真正准备过孩子具备这些能力——他们只是一直在找“下一张彩票”。

五、那些浮夸传说，是阶层焦虑的“止痛谎言”

走进亲戚家，总能听到：

  • “谁谁上了清华”
  • “那个亲戚月薪几万”
  • “有个朋友在阿里当高管”

但你从没见过这些人。
他们不是不想让你见，而是——他们根本就不存在。

这是中原地区特有的“语言尊严再生产”系统：

  • 在缺乏资源的环境中，唯一能拼的，是“语言上的体面”；
  • 现实越压抑，传说越浮夸；
  • 孩子越没希望，神话越会被重复。

这并不是谎言有意，而是现实过于寒冷，人们只能靠“话术取暖”。

六、实验班不是终点，是筛选的再加速

很多家长误以为：

“考进实验班，大家差不多，就看谁努力。”

但现实是：

  • 实验班内部分层严重，前三名可全省前十，考清北；
  • 前十名左右才有上交、浙大的资格；
  • 到了年级二十名，是典型擦线985；
  • 超过五十名的，多数去普通一本、偏远211、冷门专业。

你的同班同学，有人初中就学完了高中课程，轻松碾压；
有人在实验班内写代码，爱好与能力远超应试范畴；
有人家庭背景好，父母是教师、医生、公务员，信息灵通、学科规划早。

而那些真正的“寒门孩子”，若家庭不支持、不干预、不买书、不断投入，基本看不到他们站稳实验班——就算靠天赋混进来，迟早也会被系统淘汰。

大多数没规划、没投入、没学习生态的孩子，即使侥幸考入，也多是短暂存活，甚至会产生严重的不适应。

他们反应慢、理解慢、写作业慢，不是因为“态度不好”，而是根本缺乏基础阅读量、字形熟练度、思维逻辑、记忆机制的长期训练。

他们写字七扭八歪，不是“糊弄”，而是字写得太少、结构认知不熟、书写技能本身就是高耗能动作。

孩子学不进去，大人却只会说“加油”“努力”“我们支持你”，却从来没有人告诉孩子：

努力的路标在哪里？路径该怎么走？落点是什么？节奏怎么调？政策信息从哪里来？

而家长自己本身，也很少有长期规划、稳定努力的习惯。他们文化水平也不高，学习能力不足，缺乏教育意识，导致在孩子掉队后，既无法看清问题本质，也无力给予任何实质性补救。

最终，孩子在高压教育场中“持续失速”，家长却仍在空喊口号，“我们相信你”“你一定能行”。这不是鼓励，而是一种令人绝望的错位安慰。

七、“努力就能成功”是最危险的毒鸡汤

家长们总以为孩子不适应，是因为“个性浮躁”“态度不好”，但你仔细一看就知道：

孩子的“厌学”，往往是有阶段性的结构诱因：

1. 前期：技能缺失期

  • 没有正反馈，理解慢、书写慢、读题慢；
  • 家长察觉不到，只当“性格慢”或“不够用心”。

2. 中期：成绩下滑期

  • 成绩波动严重，比如从年级50名跌至150名；
  • 家长这才慌张，但只会情绪输出：“你分心了”“你退步了”。
  • 可能会上补习班，若问题是方法/节奏还能补救，但如果根基早已松动、节奏跟不上，补习班反而加剧厌学。

3. 后期：彻底失控期

  • 成绩太差无法掩盖，家长切换到指责模式：“你懒惰”“你不努力”“老师也不喜欢你”。
  • 若完全失去升学希望，就改口说：“学历不重要”，开始讲“没读书也能混得好”的励志故事，搬出一批不可复制的网红个案。

孩子不是不努力，而是他们在结构性失败中，被一步步推向心理防御墙。家长没提供任何技能支援，却只会输出口号和戏剧化情绪。

这不是教育，是制造溃败。

你以为孩子在读书，实际上他只是靠在饭桌角落完成作业格式；你以为努力就有回报，但在这个系统里，努力晚了，就会全盘作废。

八、失败之后：家庭如何自我洗白孩子的教育失败

当孩子彻底掉队、成绩失控、学业路径基本宣告失败后，大多数家庭不会坐下来诚实复盘问题出在哪，而是迅速进入“自我洗白”模式。

人格归因法

“他天生不是读书的料。”
“从小就坐不住，我们也尽力了。”

社会替代神话

“读书也不一定有出息。”
“我们村谁谁，初中毕业，现在做生意买车买房了。”

娱乐化榜样移植

“那谁谁网红，初中都没毕业，照样上节目赚大钱。”
“你不如早点拍视频、搞直播、整点流量。”

系统责怪转移

“老师不关心他。”
“学校差，教学质量不行。”

最终，他们把教育失败包装成了“性格问题”“社会误区”或“另有道路”，而回避了真正的问题：

从小学起就没有学习节奏管理，从初中起就落下技能链条，从高中起就在用“幻想”遮盖崩盘。

他们不承认孩子是被系统性抛弃的，只说：“这条路不适合他。”

可笑的是，他们从未带他走过这条路。

九、班级70人，老师的注意力只够用在前1/3

在中原地区，一个班级常常是60人到70人，甚至更多。但你仔细观察课堂结构、老师的提问模式、考试排名的影响，就会发现一个冷冰冰的事实：

真正获得老师持续关注与反馈的学生，只有三类：

  1. 年级前十：核心资源倾斜者

    • 老师重点关注，作为“升学光环”代表，全程重点呵护；
    • 小错误也会被个别指导，提问几率高，被主动点名讲题。

  2. 年级前100以内：课堂活跃推进者

    • 老师默认他们“可推一推”，属于“可能起飞”那批；
    • 常被安排上台写题、参与课堂讨论，和老师、家长互动频繁。

  3. 班级刺头与倒数：负面印象标记者

    • 成绩极差但“有印象”，以刷新最低分或课堂问题制造者被记住；
    • 成为“典型案例”反复提及，虽然得不到真正支持，但起码有“存在感”。

而中间那一大段——成绩中等、性格沉默、作业中规中矩的学生，他们才是最容易被忽略的一群。

这些学生：

  • 没有正反馈，也没有负反馈；
  • 家长不吵，老师不提，学校不推；
  • 就像是在整个系统里“隐身”一样活着。

最终的结果是：

被忽略的，不是能力最差的，而是“不吵不闹成绩又不拔尖”的那群人。

这些人，后来大多成为了“中等生沉默脱轨”的样本。

他们不是主动退出的，是在一次次无声的课堂里，慢慢沉下去了。

十、你以为教育是公平的，其实它是一套“可见度分配系统”

你以为教育是“孩子表现 → 老师看见 → 教育介入”的线性关系，但事实不是。教育资源的流动逻辑，更接近一套 可见度分配系统 ：

  • 被老师看见，才有反馈；
  • 被表扬一次，可能改变一个学科命运；
  • 没有被看见，就像不存在；
  • 被负面看见，就贴上标签。

某位成绩平平的女生，地理长期保持优秀。为什么？不是因为她天赋异禀，而是因为——某次地理老师当众夸了她一次。她从此喜欢上了那门课，初中好到高中。

她不是特别聪明，但她被点亮了。

反过来，那些从未被夸、从未被点名、从未被信任的孩子，连尝试都没有过。他们不是没天赋，只是从来没被“接通电源”。

教育并不平均。它从来就是：

  • 谁被关注，谁被唤醒；
  • 谁有反馈，谁才愿意努力；
  • 谁被引导，谁才能走得远。

你以为努力靠自己，其实努力本身，也需要“被允许”。

被看见，才是起跑线。

十一、一个家庭最先破产的，是注意力

很多家庭并不是没有注意力。

恰恰相反，他们很擅长观察。

他们能观察别人家的身体、胖瘦、病痛、收入、婚姻、孩子成绩，也能记住谁家亲戚在哪上班，谁家孩子有没有出息，谁家最近是不是出了什么事。

但他们很少把同样的注意力，稳定地投向自己家孩子的学习过程。

孩子到底卡在哪一道题？
是哪一种能力长期缺失？
阅读是不是跟不上？
书写是不是太慢？
理解题意是不是吃力？
作业完成了，还是只是完成了格式？
他是真的不用心，还是根本不知道怎么学？

这些问题，反而很少被认真观察。

八卦别人不会带来任何收益。把注意力收回到自己家，至少还有可能改变一个孩子的路径。

一个家庭最先破产的，很多时候不是钱，而是注意力。

没有书房，是空间缺位。
沉迷八卦，是注意力错配。

前者说明学习在家庭里没有位置。
后者说明真正重要的事情没有被看见。

而一个孩子能不能走远，最早看的往往不是他高考那几天发挥如何，而是这个家庭在更早的时候，是否愿意把时间、空间和注意力，持续放在真正值得投入的地方。

真正的教育，不是孩子有没有被逼着完成作业，
而是这个家庭，曾不曾真正为“通向希望”做过结构性的准备。

没有书房的家庭，是最早被刷下来的。

日常记录｜既然被迫听了楼下八卦隐私，我就八卦一下整个小区的升学数据来解闷一下

发表于 2026-06-26 10:10:03 更新于 2026-06-26 10:31:06 分类于 日常记录

最近是高考季，社区很多有孩子的，我看他们很热情。那我来推一推，社区的升学数据？

已知：我社区在城西，不是最好的地区，多数人是摆摊，工厂打工，开店，打零工，低薪文员。嗯，济源是工业城，我们这边不挨着文教区，所以小区是比较穷的那种。

这边的小孩不择校就去附近的太行路初中，这初中2025年一中（本市最好的高中）招收84人，全校一个年级500～600人，我取平均数，550人。
也就是这个小区在太行路上学的小孩，只有考到前84，有机会去一中，也就是必须考到前15%才行。

然后以我自己的经验，考到一中前20名（文理科），才有机会上不错的985，那一中一个年级有36个班，一个年级大约2000人，那就是2%的概率能考到不错的985。

再叠上初中的淘汰率，就是千分之三的人能去个不错的985

社区大概900户，假设都住满，一家一个孩子，如果全社区的孩子一天高考，就只有2.7个人能考进不错的985。假设一户两个孩子，只有5.4个孩子能考到不错的985。
这是理想情况，社区不一定能住满，这些孩子也不会同一年高考，如果把全社区的孩子分散到18年高考，如果一户1个孩子，那就是6年会有一个考到不错大学的。如果一户2个孩子，也就是3年会有一个考到不错985的。
如果再乘以入住率，非满员入住的情况，这个数据就更惊人的小了。

书斋｜〈叫魂〉札记：恐慌如何成为权力

发表于 2026-06-25 14:44:16 更新于 2026-06-25 16:03:45 分类于 书斋

以下为《叫魂：1768年中国妖术大恐慌》阅读摘抄，供日后回看。

作为现代中国的前奏，叫魂大恐慌向中国社会的观察者们凸显了一个特别令人难过的现象：社会上到处表现出以冤冤相报为形式的敌意。

叫魂案从一开始就带有这种令人不快的特征。

在叫魂幽灵的发源地德清，慈相寺的和尚们为把进香客从与他们竞争的那个寺庙吓跑而欲图挑起人们对妖术的恐惧。更有甚者，他们虚构了一个容易为人们相信的故事，即一伙石匠试图用妖术来加害于自己的竞争对手。这是一场戏中戏，每一出都用民间的恐惧来做文章。除了丑恶的妒嫉，还有无耻的贪婪：县役蔡瑞为从肖山和尚们身上勒索钱文，也编造出了可信的罪证。

一旦官府认真发起对妖术的清剿，普通人就有了很好的机会来清算宿怨或谋取私利。这是扔在大街上的上了膛的武器，每个人——无论恶棍或良善——都可以取而用之。

在这个权力对普通民众来说向来稀缺的社会里，以“叫魂”罪名来恶意中伤他人成了普通人的一种突然可得的权力。对任何受到横暴的族人或贪婪的债主逼迫的人来说，这一权力为他们提供了某种解脱；对害怕受到迫害的人，它提供了一块盾牌；对想得到好处的人，它提供了奖赏；对妒嫉者，它是一种补偿；对恶棍，它是一种力量；对虐待狂，它则是一种乐趣。

我们在这里所瞥见的，是否是一个已经被人口过度增长，人均资源比例恶化，社会道德堕落所困扰的社会所遭遇的一种道德报应？在这样一个倍受困扰的社会里，人们会对自己能否通过工作或者学习来改善自身的境遇产生怀疑。这种情况由于腐败而不负责任的司法制度而变得更加无法容忍，没有一个平民百姓指望从制度中获取公平的补偿。

在这样一个世界里，妖术既是一种权力幻觉，又是对每一个人的一种潜在的权力补偿。即使叫魂这样的事情从来没有发审过，人们仍然普遍的相信，任何人只要有适当的「技巧」便可以通过窃取别人灵魂而召唤出阴间的力量。这是一种既可怕又富刺激的幻觉。与之相对应的则是真实权力————人们可以通过指控某人为叫魂者，或者提出这种指控相威胁而得到这种权力。 施行妖术和提出妖术指控所折射反映出来的是人们的无权无势的状态。对一些无权无势的普通民众来说，弘历的清剿给他们带来了慷慨的机会。

这种“受困扰社会”（impacted society）为反常的权力所搅扰，它和莱斯特·瑟罗（Lester Thurow）所描述的二十世纪美国“零和社会”在某一方面是很相似的。这两种社会都发现，它们所面临的基本问题已无法通过增进生产来解决，而需要“对损失进行分摊”。

但是，两者的一个主要区别在于，在瑟罗笔下的后工业化的美国，人们被出卖的感觉是由于进步和经济成长的信念而产生并得到强化的——这种进步和经济成长一度曾使西方世界相信，所有的困难都会屈服于人类的努力，从中某些人会得益却不会有任何人受到损害。

与此形成对照，在帝制后期的中国从未有人设想人的努力能够（或应该）产生无限的进步和成长。同一个富裕的工业社会相比较（不管这个社会的贫富差距有多大），“损失分摊”在一个贫穷的农业社会是一种更为严酷的过程。当中国进入近代的时候，社会拥挤、贫穷，人们对于正在侵蚀着普通大众生存机会的种种实际力量则几乎完全没有了解。 “受困扰社会”的特殊政治就是在这种情况下产生的。

在帝制后期的中国，绝大多数人没有接近政治权力的机会，也就不能以此通过各自的利益相较去竞争社会资源。对普通臣民来说，仅仅是组成团体去追求特殊的社会利益便构成了政治上的风险。

有时，人们便会到旧的帝国制度之外去寻求这种权力；其结果就是造反和革命。但对大多数人来说，权力通常只是存在于幻觉之中；或者，当国家清剿异己时，他们便会抓住这偶尔出现的机会攫取这种自由飘浮的社会权力。只有非常的境况才会给无权无势者带来突然的机会，使他们得以改善自己的状况或打击自己的敌人。

即使在今天，让普通民众享有权力仍是一个还未实现的许诺。毫不奇怪，冤冤相报（这是“受困扰社会”中最为普遍的社会进攻方式）仍然是中国社会生活的一个显著特点。
