日常记录｜睡前刷了一点新闻，我觉得现在关于AI的一切有点疯狂～

发表于 2026-05-17 09:36:24 更新于 2026-05-17 09:36:24 分类于 日常记录

睡前我跟GPT瞎扯，又看到了OAI的消息。貌似是更新GPT的记忆系统。

现在AI概念一个接一个飞过来，我觉得很疯狂。更疯狂的是，我看到的更多的是关于技术的狂热。我没看到与这股狂热对应的伦理进展。所以我觉得这一切很疯狂，程序员拼命写AI，用来代替自己。
AI能写代码之后，我想，对效率的追求又该变态的上升了。哎，我总是好奇，以后，能被AI颠覆的一切，会不会变得越来越快？

OAI和Anthropic都在2026年试图IPO到二级市场抢点钱。
这两家公司，很难说，谁在伦理上更好一些，虽然两家在技术上各有千秋。

OAI把AI技术包装成威胁，所以他们有资格且必须把AI技术掌握在自己手中。
Anthropic把技术包装成伦理，所以他们有资格且必须把AI技术掌握在自己手中。

最近OAI重置了Codex额度，Codex出了手机版，技术上很热闹。但还有一件事，是OAI悄悄把用户的对话信息分享给谷歌和FaceBook。而且各家训练商都默认个人用户数据用于模型训练（笑）。

另，OAI的4o事件，也做的很难看。当时Anthropic借此营销了一波，承诺不会突然下架自家模型。但很有趣的是，最近Sonnet 4.5也要下架了。
OAI做的难看，不代表它的对手就一定很清白。我想，只是OAI把最难看的坑踩了，然后等其他家模型做大，也会变成OAI的。只是到了那时候，用户们早就见怪不怪了。

所以我觉得……哎，我之前很努力学技术，是我把技术想的太好了，现在去看，那些整个世界最好的技术脑子们，在努力的用技术替代自己。忽然就觉得，哎，技术是技术，智慧是智慧，生存是生存。
之前我努力学技术，除了对技术有期待，也对技术好的人有期待，但现在看，貌似这些人……也不过如此。（笑）。

哎，不过也许人就是如此疯狂，不然怎么会在几十年间，把人口翻倍到80亿呢～

语言反馈高度重合

vibe coding 时：

yes yes yes, 继续，就这样，别停，快把这个bug修了

做爱时：

yes yes yes, 继续，就这样，别停～

过程很爽，事后很空

vibe coding时：

我懂你需求，我帮你拆，我帮你写，我帮你重构

做完之后打开目录：

controller七个，service是三个，utils里躺着一堆不知道谁生的孩子

嗯，当时很上头，事后要负责

需求表达全靠对方领会

vibe coding的时候，命令模型：

感觉还差点意思
这里你应该懂吧

我不懂你说什么，但我会假装自己很懂，并且给你在项目里乱写800行看起来正确但一测试就露馅的代码

成瘾性极高

第一次vibe coding

哇，它真的能写～

第二次

我就让它帮我改一点点

第三次

算了，整个项目都塞给它生成吧

最后

没有codex，我不会开IDE
没有Claude，我不会起床
没有GPT，我不会做人

非常挑对象

喜欢Cursor的觉得

它在我 IDE 里，很贴身

它温柔，理解我，长上下文，很会陪跑

喜欢Codex的觉得

它硬核，能干活儿，还时不时重置额度

喜欢GPT的觉得

它不一定自己动手干活儿，但会先把我脑子扶正

嗯，非常的赛博择偶，非常的vibe coding

模型太快

你怎么两三秒就答完了，你真想了吗？

思考时间刚刚好

嗯……它在认真处理我

所以vibe coding最好的体验就是，要让用户时时刻刻都知道

别急，我还在里面呢

开场：

世界不分男女。
只分三种人：
会用 AI 的人，
不会用 AI 的人，
以及以为自己会用 AI、其实在给模型当免费测试员的人。

动作开始：

右手举起：Vibe Coding！
不写需求，不写设计，先让模型给我跑起来！

原地踏步：接龙虾！
进度条动了，钱包也动了，项目好像没动。

左右横移：Agent 自动化！
一个 agent 写代码，一个 agent 改 bug，一个 agent 解释为什么前两个都不靠谱。

扭胯两下：快做飞轮！
内容飞轮、产品飞轮、增长飞轮、情绪飞轮——最后我本人先飞出去了。

拍手：噫～我成了！
今天我也是 AI 原住民、生产力先锋、未来已来体验官！

结果

跑两步：debug 累死。
模型说“应该可以”，项目说“不可以”。

转身回头：新模型来了。
我昨天写的 prompt，今天过期。
我上周搭的 skill，本周被原生能力吃掉。
我辛苦做的自动化，成了模型更新日志里的一句话。

最后定格：
折腾一大圈，归来仍是人工。

尾声

要成功，先发疯；
要自动化，先手动调三天；
要做飞轮，先被新模型碾一轮。
