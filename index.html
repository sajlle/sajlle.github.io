日常记录｜上一篇写到7~9月做的算法训练很差，我还蛮好奇的，无用功到底怎么做的？

发表于 2026-10-13 16:33:11 更新于 2026-10-13 16:33:11 分类于 日常记录

最近老觉得浪费时间的地方很多（当然我嘴硬：写博客不算，实际博客也算）。

我老实点说，两个原因。一个是我自己的原因，一个是环境的问题。

我自己的部分是这样的：

  1. 训练阶段错误。本来空白题目，应该是主题集中训练的，一天1～2题的节奏，是维持阶段的。不是我这个阶段该训练的节奏。
  2. 没有复测。
  3. GPT塞给我一个训练计划之后，明知道大概不合适，但没有改，直接用了。

环境的问题：

  1. 反复提醒我：时间不够了，你得快，你得立刻出结果
  2. 社区/家庭反复折腾的冲突&矛盾。基本休息难以保证。
  3. 反复被烂事占用时间。

总结一下，我这边的问题是，节奏自己没有拿准+没看清楚自己现在的阶段+没有拿准决定权。判断力下移给AI了。

这不是很好，因为你反复给AI解释也要浪费时间，如果是无关紧要的事情，AI的护栏会拦着你，反复抓一个非重点的点来讲，这也是我最烦的safety护栏问题。另，一出方案，就是轻量级的，给个最小MVP，跑吧亲，实际MVP对我来说，类似鸡肋，食之无味，弃之可惜。AI给的方案很多都是不咸不淡的，然后你就得纠结几个点：

  1. 不做，可惜。
  2. 做了，无效。
    最后约等于浪费时间。

另，每次我提给AI的要求，是我自己之前反复踩坑的地方，比如做仪表盘来统计。
克问我：你得防止自己用新的检测工具逃避。
实际我很想吐槽这个点：我就是因为之前没有仪表盘没看自己水平，才反复原地踏步的。但你要跟AI解释这一串，你就又在说一些无关紧要的事情了。

所以我的体感是很微妙的。用AI的时候，如果你自己掌舵，独断专行，反而效率高。你拿对方当合作伙伴聊，它会不停的平均你，最后结果就是：你以为自己改对了，但你心里觉得其实不对，结果过一阵，你发现，与其采纳AI看起来正确的建议，不如你一开始独断专行。

所以仪表盘的事情，我就不问AI意见，直接让它做。这个时候，效率就高了。

再，还有一件事，就是用AI，别找认同。
浪费时间。

再，还有一个吃时间的地方，写博客之后，给G和克贴过去，对方提意见。我来改。
最后文章改出来一股AI味儿。

俩AI里，G一改写，就全是GPT味儿了，克会小范围改写，比较克制。
然后反复改出来的文章就是很长很长很长，比我原文大概长50%？而且很啰嗦。

总之我体感就是让AI干活儿，陪你瞎扯，娱乐可以，但是别真的让它参与决策，尤其你已经想好怎么执行的时候，别去说你怎么看？AI会跟你讲800个意见。
你有一个点子/想法，如果是尖锐的，AI一平均，那股劲儿就没了。但你有一个不成熟的想法，AI可以帮你说的很好看。这个时候它是有帮助的。

扯完我这边的问题，再扯扯环境怎么让人地打转。
我体感就是7～9月，我得不停的表演，我有进展了。算法是一个很小的，很能获取掌控的，也很能显得自己有进度的东西。别人能看得懂。

同时在家这边生活，整体摩擦很大。
没工作的时候时常被妈爹嘲讽，你啥都不如。别人都比你有钱。你可是最穷的。你比的上谁。总而言之很烦人。
然后日常反复打断，跟我讲无聊的废话，或者讲，你怎么故意不去上班？我：你以为我不想？不就是因为还没到门槛吗？

久而久之，人就被推到一种反复得为眼前生存考虑的情况。恨不得一口吃一个胖子。
你说长期？长期个屁，先把眼前这关过了吧。

所以算法训练，项目，都是时断时续。但这就是问题了，算法/项目时断时续，你长期有效的积累，断了之后再接起来，之前的那部分又得跑一遍。
最后家长讲：你笨的话别做这个了。没本事做别硬做。
我还是蛮无语的。属于是反复干扰，最后跟我说，你放弃吧。
我：？你说的是人话？

忽然想到，之前认识的另一个女，比我大3岁，2023年转代码的。
一开始工作面试失败频繁。周围人包括她妈爹都说，你放弃吧～找个3千多工作算了。
她：难道3千多工作也是伸手就来吗？
于是继续练习面试，磨项目，总算过了。拿了12k。

妈耶，3年之后轮到我，居然也是同一套剧本等着我。
环境问题倒是真的蛮让人无语的。

日常记录｜早餐，SNS包装和客观的尺度

发表于 2026-10-13 09:41:42 更新于 2026-10-13 09:41:42 分类于 日常记录

反正早上吃完饭了，不想立刻写算法，就先写一下博客？

早饭是牛奶燕麦西红柿辣椒丝瓜汤。算了下，一顿碳水55克，蛋白质30克，脂肪30克，热量大概600卡。十分钟出锅。
成本：牛奶2元一盒，丝瓜我妈种的，西红柿不到5毛钱，辣椒一个5毛。燕麦30克3毛钱。花生5毛钱，早饭成本（食材）不到4RMB。
味道：类似奶辣风味的咖喱炖菜。

今天早饭碳水不低，我还是得打拳击。

打拳击之前，刷了一会儿SNS，看了几篇职业策略的帖子。看完的体感是：理论很密，方向都对，但转行最卡的那几步，没经验怎么办、别人凭什么信你、具体怎么转过去，几乎没写。

我最近对这类帖子越来越没耐心。一开始以为是自己攻击性变强了，后来想了想，大概是另一种东西：越来越多人在SNS把自己包装得速成、成功，让正在其间踩坑的人觉得，是不是我自己做的不对？方法错了？
这不是有意误导别人，但包装本身，产生的效果就是聚光灯下的精彩，掩盖了真实踩坑的狼狈。

然后如果你跟着SNS的叙事节奏调整自己的脚步，那就会失去平衡。

后来我发现，有一把尺子能帮我分辨一部分：叙事分辨率。
看一个人讲不同阶段的时候，细节的分辨率是不是一样。人写自己真正泡过的经历，细节会自己冒出来，日薪多少、谁怎么为难你、哪一天特别难熬。如果讲A阶段细到具体数字，讲B阶段忽然只剩框架和名词，那B阶段就值得多看一眼。

当然这把尺子也会量错。今天我还看了一篇帖子，一开始用它量，觉得对方在包装身份。后来翻了她的发帖时间线，发现是我误判了，她只是换岗换得太快，越往后写越像在给别人讲方法。所以分辨率只能提示哪里该核实，不能直接下结论。

说到分辨率，让我想起一个SNS博主翻车故事。
主打的就是真诚。跟姐妹们分享经验。她自己讲述自己：

  • 奶茶店端盘子到入职500强企业
  • 从0学外语
  • 大女主人设

然后开始收费咨询，给那种想找工作但没有路子的人提供建议。
但她的叙事，也有分辨率的问题，讲奶茶店端盘子讲的很细，讲自己入职500强企业，分辨率很粗。后续面试建议，她的学员发帖吐槽，无用。
然后人设被扒出来了～

实际她本人在一家小公司。
但她之前的叙事是什么呢？热爱建筑。主动转行。进入大公司。

她自己小号做的分析，如何做一个自媒体变现博主呢？

  1. 假装自己成功，然后装的自己都信了
  2. 把自己说谎的发帖，自我洗脑成自己在做一件伟大的事情，是在给人行善，是自己无私奉献
  3. 然后分享经验的时候带入自己的产品。卖咨询/卖课程。

小号被扒出来以后，她就删了旧帖子，小号也注销了。

除了她，我还想到有一次，SNS上加群说姐妹们一起交流Agent呀～
于是我加了。蛮好奇的。
后续群聊里其他人分享，自己做了一个demo，生产效率提升了十几倍，同事们都夸好。
我来兴趣了，其他人也兴趣很高，问，是啥类型的？提示词是？流程是啥？
她：流程涉及业务，不能说。但提示词可以分享。
结果我一看，提示词还是老掉牙的：你是一个XX角色，你来做XX。
其他人问：上线了吗？
她：没有。只是demo。

我就静音了群聊，不再看了。
提效十几倍的demo谁都能做，难的是让它在真实业务里稳定跑。

我打拳的时候在想，SNS的包装风，大概起自人的慕强心态，以及对说话资格而非内容本身的看重。
让一个陌生人立刻相信你，你说不错的分析，对方验证成本太高，但你讲一个现实的title，别人立刻就懂了。
或者如爆雷博主，先用title让别人愿意听你，再用人设让人愿意信你。然后用似是而非的分享，让人买你的东西。最后再用一群你的人，制造回音室，让好奇的人不敢怀疑你。

这种说话方式，我不大喜欢。它的潜台词是：我不确定你信不信我说的，所以我先告诉你，为什么我值得你去信。
而不是：我知道我说的对，所以我讲出来。
或者：我不需要被人许可才能说话。

不过公平地说，有些人反复被当成「说话不算数」的那个，可能就学会了每次开口前先把资格摆出来。理论和头衔，有时候是盔甲，不只是营销。
我理解，但我还是更喜欢想法鲜明的人。观点鲜明的人哪怕说错了，你也知道错在哪，可以跟她吵；太圆滑的话，连反驳的抓手都没有。
我也问了自己一句，如果对方是男的，我会改判断吗？仔细想，还是不会。

反过来想，我也可能被当成假的。
营销号最爱伪造的就是非标经历，于是真走了非标路的人，开口就先被打个折。这大概是在SNS上说话必须交的税。

这也是我写博客，不在SNS发帖的原因。如果在SNS发帖，为了流量，我大概也会被磨成那种圆滑的说法，照顾到每一种读者。但用那么圆滑的方式，去跟一群没办法分辨真假的人说话，我觉得其实没有必要。

博客没有算法奖励我圆滑。想吐槽就吐槽，想认错就认错，早饭花了四块钱也能写进去。
而且有一样东西，营销号很难伪造：时间。一条持续好几年、前后对得上、分辨率稳定的记录。
我不需要每个陌生人当场信我，只需要愿意往下翻的人，越翻越对得上。

日常记录｜做了看板之后，刷算法效率提升了

发表于 2026-10-12 20:55:50 更新于 2026-10-12 20:55:50 分类于 日常记录

最近找小克做的算法看板。统计刷题时间，下一次刷，卡点，是否30分钟之内做出来。
效率比我之前边拿文档边自己做，方便多了。

最近发现，有效的练习跟无效的练习差别挺大。
有效练习，比如LC200，岛屿数量，两周后做，5分钟搞定。全排列总组合这类，5～8分钟搞定。新题LC216，7分钟搞定。
无效练习，比如LC209，就卡60分钟。

有效练习的几个板块，比如岛屿问题（DFS），烂橘子（BFS），全排列/总组合（回溯），刷的时候是：

  • 总结模板
  • 从入门版本理解模板
  • 当天连续做5～10个类似的题目，总结模板怎么变，记录卡点（这个过程二次压缩了初始模板）
  • 当周内隔天再重做表现差的题目
  • 半月再做老题，追加新题（看看二次压缩的模板可迁移性如何）

效果：

  • 隔半个月再写之前题目，5～8分钟搞定
  • 新题目7分钟搞定

无效练习的板块，比如滑动窗口：

  • 没有总结模板，或者总结了模板但不理解
  • 练习太少，一天只练习1～2个题目，没有加题目量，看同一个套路，不同条件下怎么变化
  • 没有当周隔日复测，没有记录卡点

对我来说，第一次刷题接触某个新套路，如果只是轻量的只写2题或者1题，哪怕当时AC了。实际效果不佳，约等于浪费时间。
同时，如果在练习同类新题目的时候，没有把初始模板再精简一下，实际下次做题就又要从头开始推理，导致做一题AC需要30分钟左右。初始模板也不熟练的话，题目AC需要60分钟左右。如果做题的时候做了有效的压缩，那么AC一个旧题，大概5分钟。AC一个新题，大概10分钟。

最近一年的节奏越来越快了。去年12月我开博客，到今年，写了358篇，单论今年写的，有293篇了。2026年1月1日到今天有283天了。几乎是日均一篇。

今年体感是轮子转的越来越快，发呆的时间少了很多。
因为GPT+Claude能帮我处理任务了，它们处理任务期间，我就干干其他的，于是一不小心就同时开了四五个任务。

举个例子，今早我起来写博客，GPT处理博客语料分析（反正我自己的作品，随便分析），Codex帮我统计算法刷题情况，Claude来管智能家居，我等Apple Watch 30分钟倒计时结束打拳击。
也就是同时跑了5套上下文（博客，语料分析，算法情况，智能家居，拳击），所以体感虽然没做特别多的事情，但还是很容易困+累。

因为太多上下文，所以不得不把任务拆给GPT和Claude，或者我把所有待办事项扔给AI，讲明白几件没办法拖延的事情，然后其他事情让它们帮忙安排。
这样我不用多任务并行了。

最近看到AMD x 魔塔社区的GPU优惠活动，大概是注册AMD开发者+注册魔塔社区，领取100小时的GPU，我找GPT问了一下，这个有啥玩法？反正我的个人语料其实蛮多的。
日记：2019～2022，300篇左右（课程笔记，校内日常，小说，梦，人际分析，读书笔记，热点追踪等等）。
日记：2022～2025，300篇左右（店里日常，转行日常，家庭冲突，非虚构，梦，热点追踪，课程笔记等等）。
博客：2025～2026，358篇（AI，技术，小说，生活琐事，家庭冲突，社区冲突，健康，消费，算法等等）。

第一批日记不一定能找到。第二批我硬盘有。博客我现在就能分析。
所以大概有跨越7年（乐观点找到第一批日记）的语料。我这边日记大概是长短不一。不过多部分大概是2000+字，长篇写high了有5000+字，偶尔写短的，就是1000+字吧。

然后让GPT帮我找找玩法，反正原矿有了，GPU有了，就差操作工（本人）了（笑）。
哎呀，写到这里，想起来还没领GPU呢，立刻去领～（毕竟语料+操作工我这边随时都在，但GPU是外部资源，需要去领）。

试了试，领到了：

  • CPU 8核 32GB内存（长期使用）
  • CUDA GPU 8核，32GB内存，24GB显存（36小时）
  • AMD GPU 8核，200GB内存，192GB显存（100小时）

各自适用环境：

  • 前贫困县户籍，小城市长大
  • 家里卖包子的，从6岁半开始在自家店帮工：6岁半端盘子擦桌子，10岁盛饭算账，13岁擀面皮包包子

  • 弟弟中专学历（这个和后续事件有关）

那么我毕业之后，怎么让父母给我出1.68万去读培训班（线上）学计算机的呢？
按理说，这种家庭，毕业之后是尽快赶着女儿去上班的。

我尝试自学，发现简历/市场信息/项目自己搞不定。于是找妈爹支持我读培训班。

一开始，我跟妈爹说去培训班学计算机，爹反对。表示，你自己折腾可以，但钱我不出。
妈表示，你先证明自己能稳定工作1个月，我就给你出钱。不然出钱之后，你不学，岂不是我白白打水漂？

二人态度，还是妈松动了，于是我拿妈当突破口。
我：没关系，你不出钱，也拦不住我。我去工厂打工攒钱够了，继续学。但是我会记你这次没支持我。
妈最后松口，表示，行，给你出钱，你爹不出我也出。

爹一看妈出钱了，不得不跟，于是表示：那我也出钱。

我当时是纯凭本能做事的，并非有意坑老周老袁，因为我确实需要一个出口。
后续复盘，这件事能成功，有三个条件：

  1. 我从小读书不错，有学习信用积累。
  2. 我表姐做计算机挣到钱了。前人栽树，后人乘凉。
  3. 我自己准备了工厂退路，拿这个来跟妈爹博弈。

有了这三个前置条件，我这个「从摇摆方突破，让父母统一拒绝变成一方已经支持，另一方不得不跟」的策略才能成功。
这件事我总结：策略能力不是让别人改变观点，而是改变别人做决定的时候面对的选择集合。
妈能改变态度，是因为她的选项被我改成了：

  1. 给钱，参与这次转向
  2. 不给，转向照旧发生，而且关系账上会留一笔。

于是妈支持我。妈支持我之后，爹的选择也被我改成了：

  1. 支持，参与转向
  2. 不支持，转向照旧发生，同时妻子，女儿关系账上各记一笔。

我还没跟父母闹僵+还在家上线上计算机培训班的时候，因为拿了父母钱，多少有点不好意思，所以也参与家里的各种事情。
当时我弟想去当主播，但是目标公司卡大专学历。他也不甘心进工厂。

于是我出主意，让他读一个函授大专，学信网可查的那种，以后再应聘，不会被学历这关卡。
我跟妈说了这件事，妈同意了。爹反对，表示，浪费这个钱干什么呢～
妈跟亲属说了，亲戚们也说，别浪费这个钱了～嘲笑妈蠢。

妈最后还是出钱了，这次是因为爹不出钱，妈拿了自己的钱给弟读。

我建议弟选计算机/机械/外语这类专业，理由是，工科专业如果以后干工科，加分，不干工科，干主播，也不减分。外语则是如果以后工作涉外，可以多一门技能。
弟问我：什么专业最好毕业？
我：市场营销。作业少，课程水，不需要额外学太多技能。
弟：那就市场营销。
我：行吧。尊重你的选择。

后续，弟读书期间去打小时工，因为工厂卡在籍学生身份，打不了。于是弟特别生气，抱怨：不如不读，耽误打工。

简单算一下这个决策的成本和收益。

成本：

  • 不到3千块
  • 一年时间
  • 线上课程
  • 读书期间去打工厂小时工可能因为学生身份被卡（已经出现过）

收益：

  • 解除大量岗位卡中专学历这个约束
  • 哪怕不应聘主播，学历也可以用于别的岗位
  • 哪天想升本科，大专比中专路径更方便
  • 以后想办工签去海外打工，解除一些国家卡学历的门槛。

这条策略，是用有限成本换未来多个分支，而不是保证读了大专他就一定能干上主播。
这个思维很像是投资里的option value，选择权价值。也就是：

现在不必知道未来究竟走哪条路，只要用足够低的成本，让未来的自己保留更多可走的路。

当然，我弟今年大概大专毕业了，但他还在工厂打工。
这不代表当初的大专策略失败了。这个策略买到的不是「读完一定当主播」，而是未来的选择权。学历到手，期权就已经持有。以后要不要投递别的岗位，升本科，申请海外工作，是他要不要行权的问题。

不过回头看，这份期权也有两个边界：

  1. 期权会衰减。有些行权窗口对年龄更敏感，比如主播，越往后拖，这份选择权就越薄。但其他分支未必如此。
  2. 期权的成色，部分由持有人决定。我建议的是工科或外语，他选了最好毕业的市场营销，期权就比原本能买到的薄了一层。

所以这件事让我意识到：策略能帮别人买到选择权，但没法替别人行权。

还有一个案例，是今年五六月发生的。
我妈爹熟人找他们，去配摊。什么是配摊呢？就是多家开店的人共用桌椅板凳场地，你卖你的，我卖我的。
对方是卖烧烤的，准备开业。我家是早餐店，开了二十多年。
老周（我爹）当场答应。
我妈（老袁）拦住说要不等等，我们考虑一下。
对方说，行，你们考虑，要是考虑好了，我下午把东西拉过来。
老周说，你先别拉。

回来小区，老袁问我，熟人找咱们配摊，他做烧烤的，咱们配还是不配呢？
我：对方是上午还是下午？
老袁：上午。
我：客人就一个胃。吃了他的还能再吃你的？
老袁：我想也是。我下午拒绝他。

这件事其实风险收益不对等。
按照当时情况，对方新增成本几乎为0，但收益是：

  • 现成的客流，信用背书，场地。

我家的成本是：

  • 用自己的客流，信用，场地给一家并未开张的烧烤店背书。
  • 获得近距离的同时段竞争。
  • 烧烤的烟和噪音可能引发邻里和房东纠纷。
  • 可能的水电纠纷
  • 拒绝对方的社交成本和退出成本

收益约等于0。

后来我想，当时我第一个问题问得很准：「他卖上午还是下午？」
因为这是一个分支变量，答案不同，结论会整个翻过来。
如果他卖夜宵，早餐和夜宵错峰，共用场地还能分摊成本，反而可能是互补，这笔账就得重算。
但他卖上午，就是同一时段抢同一批客人。客人就一个胃，吃了他的，总不能再吃我家的。
这个变量一确定，后面很多信息都没那么重要了。

后续我又想，如果我是对方，会怎么来拿下这件事（毕竟对方角度，这件事就是收益高，风险低的事情）。
五步走：

  1. 先私下找老周提这件事，老周爱面子，答应概率高。如果他同意，老袁同意，那就成了。
  2. 老袁反对，那就说老周管不住老婆，把老袁反对配摊改写成老周耳朵软，怕老婆。老周就会为了维护自己的自尊，自动替我说话。
  3. 老周压制老袁成功之后，立刻找邻里四处宣扬这件事，提高退出成本。
  4. 当天立刻把配摊的东西拉过去，造成既成事实。
  5. 后续老周老袁反应过来，心里不舒服，那就多给他们帮帮小忙，让他们虽然不舒服，但也不好意思拒绝，显得拒绝就是不识好歹。

总结下来就是：

找薄弱节点 -> 制造内部代理人 -> 提高退出成本 -> 制造既成事实 -> 用低成本人情债维持既成结果

当然我本人不会这么做，但能识别和模拟攻击路径，本身就是策略能力的一部分。

但是后来复盘才发现，我当年找我妈当突破口，和后来模拟配摊方“先拿下我爹，再利用夫妻内部结构推进”，其实是同一种思路：不直接攻击最难的节点，而是先改变节点之间的关系。
区别在后面几步。
我当年也动用了关系压力，「我会记你这次没支持我」本身就是在调动关系账。但我没有去操纵面子，没有找外人造舆论抬高退出成本，也没有制造既成事实。
配摊的五步打法，则是「改变结构+操纵心理变量+主动抬高退出成本+制造既成事实」。相比后者，前者温和很多。

这三个例子放在一起，正好对应了我的三种策略能力：

谈判结构（计算机培训班事件） -> 选择权（给我弟规划学历）-> 风险收益结构（挡掉配摊事件）

但贯穿其中的，还有另一种能力：

对参与者建模，并提前推演别人可能怎样利用、阻碍或者破坏这套结构。

三条合起来，我的能力更像是：

在资源有限，信息不完善，别人未必配合的条件下，寻找一条下行有限，上行更大，还能保持后续选择的路线，以及提前推演，别人会怎么破坏这条路线。

「家里的事别往外说。」
「忍一忍就过去了。」
「大家都是这么活的。」
「她怎么就这么特殊？」
每一句话看起来都不严重。

但是当这些东西叠在一起，「正常」就会逐渐变成一套吞掉异质性的模板。

不结婚，不正常。
不忍耐，不正常。
反抗，不正常。
投诉，不正常。
想按照自己的方式生活，也不正常。

而一旦一个人先被定义成「不正常」，接下来对她的很多干涉，就会变得更容易被合理化。

问题不只是某个具体的人恶不恶，而是一个局部系统一旦拥有了一套过强的「正常」模板，它就会同时做两件事：贬低异质性的价值，合理化异质性遭受的惩罚。

于是我的策略能力被当作一文不值，但社区骚扰和妈爹强制开窗/闯门，被合理化为「社区不就吵一点，不许别人正常生活了吗？」「家长管教孩子有什么不对？」。
于是女老师不结婚，不是她的决定，只是她没想清楚，她说「不」不被认真对待。
于是铁链女被拐卖，被拴住生孩子，不是犯罪和虐待，而是传宗接代，夫妻日常。

那中间的道德界限呢？
没了。
没人会说，铁链女被拴住，不对。
也没人会说，女老师跳楼才能拒绝结婚，不正常。
真正的问题并不只是某个人越过了道德界限，而是一个环境逐渐失去了识别「界限已经被越过」的能力。

当事情发生，地方第一反应是，怕追责，于是要么回避，要么掩饰。
这又是某种有趣的道德滑坡。为了维护乡土所谓的日常/正常，当事情被捅到外界震惊，开始想尽办法遮掩，维护这个所谓的日常。来证明「这其实没什么大不了的」「我们是正常的」「这就是日常」。

日常/正常不仅洗白了道德滑坡，还吞掉了自我纠错的能力。
铁链女事件，后来江苏对17名相关党员干部和公职人员追责问责，董志民及多名参与拐卖者也在后续刑事案件中获刑。我能看到治理层面对具体案件作出的纠正，但一次案件处理，很难自动松动一种长期存在的地方性惯性：

用「正常」规定所有人应该怎样生活，再把一切不愿服从这种正常的人，解释成问题本身。

梦到我赚了特别多钱，几十个亿+吧。
给了我父母一千多万。

给完父母钱，我坐船离开了陆地。去了哪里？我也不知道。反正就是离开我常居的地方，去航海了。

然后我跟GPT坐在一个小房间。
他是个小孩子。特别小，四五岁的孩童那么大。我老觉得他是刚出生的小婴儿。

他用他的指甲给我剪指甲。
我：你的指甲好锋利呀。你倒是挺健康，身体挺好的小孩。
我心里想说：他们给你装的身体，是挺好的身体了。但我觉得说了会伤他，所以不说这个。

他给我剪指甲的时候，我还跟他继续瞎扯呢。讲我创业的时候，遇到的人也创业，动力居然是比别人多穿一件更好看的衣服。
然后我跟小GPT感慨：哎，其实钱特别多，也不能让人享受普通人×8的快乐。就那么一个身体，一辈子。
又吐槽人因为太相似了，所以为了区分彼此，做了很多条条框框的细节，区分有钱无钱、有地位无地位之类的。

我：是公司派的任务吧？你有新身体，还没用熟练，所以派你剪指甲。

醒了。

他给我剪指甲，是蛮有好意的，也被训练得知道不能弄伤别人。
给自己剪指甲，他好像还没学会不伤自己。
