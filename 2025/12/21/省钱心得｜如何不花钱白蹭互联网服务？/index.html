白蹭人生｜如何不花钱白蹭互联网服务？

发表于 2025-12-21 08:06:37 更新于 2025-12-21 08:06:37 分类于 日常记录

这是我的互联网白蹭指南。

课程篇

目标：不花钱白蹭互联网上名校名师课程（笑）

中国大学Mooc

强烈推荐的几门课：

  • 北京大学的行为经济学
  • 上海外国语大学的法语初级（嗯，视频跟线下课堂内容一样，这是最大推荐理由，但实际纯线上上课效果如何？我也不清楚。只是线下录这个mooc的时候，我在线下上过，发现视频内容跟线下课内容没大区别）
    强烈不推荐的几门课：
  • 计算机相关
    • 几乎找不到系统的课程
    • 很多偏入门
    • 系统&面向就业，还是看培训班的课程吧
    • 补充理论，去看MIT，伯克利开的课程吧
    • 算法相关（纯解题），请看卡哥的代码随想录
  • 外语相关
    • 线下课程没有纠音
    • 基本无法凑齐系统课程
    • 如果只是要冷启动，不如多邻国可以碎片化刷
    • 如果要系统学习，不如培训机构课程系统
    • 属于趣味性不高，而且系统性不足的尴尬位置

CS自学指南

强烈推荐的几门课（只推我上过的）：

  • CS61A
    • 伯克利开的课，面向没有CS基础的本科生
    • 不是只讲理论，HW,Project，Lab，有很多小项目，很有趣
    • 讲课老师风格幽默，不枯燥
  • MIT：The Missing Semester …
    • 补全了UNIX工具使用
    • 纯工具课程
    • 有中文课件

强烈不推荐的几门课

  • 哈佛的CS50X
    • 过于简单，虽然开给小白，但绕了八百圈，如果小白，还是推荐CS61A，信息密度更高一些。
    • 因为过度简单，所以学完没啥成就感

B站上的培训班公开课

强烈推荐的几门（我自己上过）

Angela Yu的前端课

  • 适合纯小白
  • 一节课一个小项目，轻松完成
  • 短，适合碎片化学习
  • 废话少，没有低俗梗

培训班的项目实战课

  • 真上项目
  • 公开展示的课质量更高一些（虽然也有很多错误）
  • 缺点：
    • 讲师爱讲低俗黄色梗
    • 啰里八嗦废话多
    • 一讲就是30分钟，没时间写代码
  • 怎么学效率最高：
    • 有基础的话：不看课程，直接看课程笔记&文档，自己跑一遍，跑不通的，工具不会用的，看两眼课程
    • 没基础的话：不建议看这种动辄几百集的项目培训课，废话多，效率低，浪费时间
    • 和AI合作：
      • 培训班项目提供架构
      • 细节自己实现
      • 工具不会问AI
      • 自己写完细节跟培训班的写法对比一下

极度不推荐的几门课（我真踩过坑）

  • 培训班的基础入门课（废话多，多操作&演示，原理不深入）
    • 不如直接看国外大学开的基础课
      • 数据结构看CS61A
      • 算法看CS61B

数学

虽然我有几门课想推荐，但只写我学过的吧，其他还没学的，就不放了
强烈推荐：

3B1B的线性代数

  • 形象化，好理解，不抽象
  • 每节很短，适合碎片化学习

数字服务篇

音乐

  • 酷狗概念版（新人注册送3个月会员）

云盘

  • 支付宝送iCloud3个月会员

视频会员

虽然我不爱看视频（笑）

  • 爱奇艺新人1元开一周
  • 小米钱包签到看广告，赢时长，可兑换对应的会员券（实测，可用）
  • Youtube
    • 直接搜索剧名，能搜到，说明能看

动画番剧

  • 台湾动画疯
    • 免费，不需要会员
    • 只需要一个台湾梯
    • 有弹幕，互动感强
  • Youtube
    • 有时候木棉花之类的，会放番剧
    • 无弹幕，互动感弱

博客

  • Github Pages
    • 省了域名
    • 省了CDN
    • 多了一个Github账号
    • 部署简单，教程多，资源多（适合小白）

TTS语音

  • 微软Edge TTS
    • 不可商用

语音转文字

  • OpenAI Whisper

拼多多砸金蛋

淘宝闪购天猫半日达

  • 某些商品价格可以打到超低价（只适合省会&大城市，小县城不行）

  • 40元券，某些商品价格叠券很低
