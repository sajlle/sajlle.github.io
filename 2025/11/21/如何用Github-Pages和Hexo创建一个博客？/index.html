如何用Github Pages和Hexo创建一个博客？

发表于 2025-11-21 分类于 技术手记 ， 博客搭建

登陆Git

用Token当密码

  1. 打开Github网页，登陆自己账号sajlle
  2. 右上角头像 –> Settings
  3. 左侧拉到最下方 –> Developer settings
  4. 选Personal access tokens
  5. 点击Generate new token
    • Note随便写，例如hexo-blog之类
    • Expiration：可以选90天
    • Scopes选：repo
  6. 点生成
  7. 复制这个Token，保存好（只会显示一次）
  8. 这个Token就是以后git push时的密码

新建Github仓库

  1. 打开Settings，选择新建仓库
  2. 仓库名称写成username.github.io
  3. 选择公开
  4. 新建仓库的时候，不要勾选
    • Add a README file
    • Add .gitignore
    • Add a license
      否则后期给仓库推送博客的时候，会推送失败

  1. 新建一个空目录，比如my-blog，把脚本放进去
  1. 把脚本内容贴进去，保存。
  2. 设置脚本执行权限
  1. 运行脚本
  1. 按照提示输入：

之后博客流程就是

  1. 本地写文章

    - 目录：/(root)

等几分钟，用浏览器打开：https:\\username.github.io
