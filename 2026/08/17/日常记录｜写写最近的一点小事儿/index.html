日常记录｜聊聊关于社保实缴，AI冲击下的低门槛低薪水白领岗位以及我转技术的时候被质疑的点

发表于 2026-08-17 09:35:30 更新于 2026-08-17 10:26:09 分类于 日常记录

嗯，又是做噩梦睡醒，那股吓唬人的劲儿现在还没消除，我就随便写写日常好了。

最近看到社保实缴的新闻，我体感是工资越高越不吃亏。所以，还是找个工资高的工作吧。
再，三年多前，我吐槽月薪只有4千左右的白领工作，会让人陷入长期的焦虑，因为工资低，导致日常都要紧巴巴的缩减开支。所以没多久，我就辞了这工作，开始一门心思搞技术。
当时很不被理解，因为技术的收入虚无缥缈，哪怕理论上高。但低门槛白领的工作，立刻能见钱。而当时我妈爹和亲戚们对我的要求就是：「别想工资高不高，先拿到钱再说」。
我的想法是：「为了现在能到手的钱，长期维持在一个紧巴巴的开支里，会慢慢套牢的」。

今年很有趣，AI冲击 + 社保实缴，这类低门槛 && 低薪水的白领工作，已经开始被两头挤压了。
AI冲击导致日常工作量增加 && 门槛更降低 && 竞争的人更多 && 老板想裁员降本增效。AI冲击的是低门槛 + 日常任务量。
社保实缴，冲击的是老板那边的用人成本，举个例子，之前一个员工5千工资，企业用工成本可能只有6千，但社保新规出来之后，同样一个人，发到手5千，但企业付出的成本可能是7千，如果你是老板，你怎么办？两条路：1. 降薪。 2. 裁员。
两箱叠加，员工那边的体感是：1. 任务越来越多 && 要求越来越高。 2. 竞争越来越激烈。3. 担心被裁员/降薪。

而低门槛白领工作的特殊点在于，因为工资足够的低，降薪&&增任务之前已经很卷了，算是在生存线上，今年两头挤压之后，这类工作提供的缓冲空间会越来越小。

但，公平的说一句，其实哪怕没有AI冲击 + 社保实缴这两个变数，低门槛白领工作也很难长期干。这两个变数只是提前把之前能用来遮屁帘的东西撕下来了，仅此而已。
没有被两头挤压的时候，父母亲戚能夸一句：「我女儿/儿子在xxx城市干xxx工作」「哎，啥都别说了，有工作总比坐家里强，好歹孩子们不跟我们伸手要钱了」，屁帘被揭下来之后，其实很难再这么说了。

嗯，万事万物皆有代价。不规划，是有代价的。只是这个代价延迟结算。

至于说那三年多之前我被怀疑「好高骛远」「心比天高」，我觉得是挺委屈的，我又没有要求很过分，也没有要别人替我承担试错成本，技术是我自己学的，学技术期间被骂不工作，啃老，也是我挨的骂，到底成不成？失败了怎么办的风险也是算我自己头上的，我只是想主动选一条相对来说更「安全」的路子，仅此而已。
所以我回忆起来，会有一丝丝的好奇，是我要求太高？还是我身边的人根本不考虑未来？

我有一个浅薄的推测，我想不是他们不考虑未来，而是他们觉得「大家都这么做，就是安全的」。
所以毕业之后立刻随便找个工作，能有现钱就行。为什么不怀疑这个思路可能危险？因为过去十多年，周围人都这么做，也没见出过什么岔子。但……环境会变，技术会变，产业会变，政策也会变。以前看起来没有出大岔子的路，未必是真的安全，可能只是环境比较好，掩盖了其中可能出岔子的地方。

而「大家都这么做」，在这些人那里，是一个「模板」，「模板」是安全的，因为模板之后，藏着「大家」。
但，「大家」本身，就一定是抗风险的吗？我觉得得分一下，如果模板背后的「大家」是被动承受的&&没有议价权的「大家」，所谓的「大家都这样」，只是一种安全幻觉。

如果继续往下推，模板除了毕业要立刻工作，别长远规划，只要先拿到现金就好，还有一整套地域运行脚本，比如：

  • 找工作之后快速成家
  • 成家之后快速生孩子
  • 生孩子之后养孩子
  • 养完孩子给孩子带孩子
  • 女孩要像个女孩样，不许愤怒&生气
  • 男孩要像个男孩养，不许「不像个男人」
    ……

凡此种种，非常之多之细，符合这套模板的人，更容易在某个地方混的更好，有更低的解释成本，而这样的人，我想称之为「地域模板人」。
反之，如果你不是「地域模板人」，不按照地域的「模板生活样本」走，你会付出不少额外的成本来证明自己「不是异常」。

昨儿我刷视频看到某地地铁某女子夏日穿着棉衣坐地铁，被人拍下来发网络上，说是精神病。
我挺震惊的，震惊的点在于：「谁规定夏天地铁不能穿棉衣的？穿棉衣就是精神病？」那偷拍别人然后放到网络上蛐蛐，就不是精神病了吗？这就很正常？
而且第一时间用精神病解释这女的，挺有意思的，我想想，其实如果认真想的话，可能是地铁空调大，比较冷，有些人怕冷，穿棉衣。或者是刚从冷气比较大的地方出来穿棉衣坐地铁懒得换衣服了。或者是生病，怕冷，或者是月子期间出门，等等。没有所有的前置考虑，直接给这人贴精神病标签，然后拍下来，发网上，一群人一起八卦。
我还是挺震惊的。

这件事跟「模板人」有啥关系呢？
我想的是，评论区以及偷拍这女的放网络上的人，其实也是模板人，他们的模板就是「夏天坐地铁必须得穿夏天的衣服」。不符合模板的那个女的，穿了个棉衣，于是触发了集体识别，被怀疑「精神病」「受刺激了」「脑子有问题」，但这么快下结论的时候，他们并没有给对方留一个解释空间。
这件事让我震惊而且警惕的地方就在于此，不是他们集体猜测这女的精神病，而是他们把一个素不相识的，只是因为没有符合穿衣模板的人，快速定义成精神病，这中间甚至没有一点留给对方的解释空间。

这件事其实也跟我当初学技术被指责是同构的，我本地的模板是毕业就找工作，哪怕工资很低，如果不符合模板，立刻被识别为异常，中间甚至没有一个余地让你解释。

于是地铁女子被说是「精神病」，我被迫不停解释自己不是好高骛远，这就是「证明自己不是异常的额外成本」。
但我们该付这种成本吗？仅仅因为不走本地模板而已。又没有真的损害到谁的利益。

再扯回到模板本身的安全幻觉（笑）。
模板本身降低的是「解释成本」「不需要额外证明自己不是异常」，但它未必真的安全。
而且模板本身形成了一种特别有趣的状态，自动规训（怀疑）不符合模板的人，从而让整个地方的秩序整齐划一。如果功能上说，它有秩序的功能。
但……有趣的来了，这种秩序不服务模板人，而是服务要用模板人的人。

嗯，所以很有意思的，自豪自己是「模板人」的人，未必在职业上&&生活上有多大的竞争力。
因为你模板，他模板，我模板，你我他水平都那样，想的都差不多，能力/习惯都标准化，那太好了，很适合整齐划一被管理，被替换，被当标准件使用。

说来说去，又拐回去到了一切都有代价这个点上了。
嗯，不当模板人，会付出额外的解释成本，忍受被蛐蛐，被当精神病，当了模板人，不需要付额外的解释成本，但……要付出另一种成本，也就是缺乏外部迁移能力，被模板套牢的成本。
两相比较，我还是觉得后一种成本更高。
