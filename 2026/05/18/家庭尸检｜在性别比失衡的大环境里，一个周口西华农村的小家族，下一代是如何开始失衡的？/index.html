家庭尸检｜在性别比失衡的大环境里，一个周口西华农村的小家族，下一代是如何开始失衡的？

发表于 2026-05-18 13:51:29 更新于 2026-05-18 13:51:29 分类于 日常记录 ， 家庭尸检

昨儿因为有点难过，就顺手盘了我爹这边，我的同辈们的情况。

两代人学历对比，第一代学历高峰是第二男，最高高中，第二代学历高峰是女孩，一个985，一个211。

我爷爷有五个子女，三男二女。都结婚成家立业，至今五个子女都健在，最大的七十岁，最小的五十岁。最高学历是高中，也就是第二男，其余是小学毕业。
五个子女每人生了两个孩子，也就是我这一辈。六男四女。最大的三十八岁，最小的二十五岁。最高学历是985，也就是四女里最大的，其次是211，也就是四女里年纪最小的，再次是本科，是六男里年纪最大的以及四女里其余两位。其余则是，2男初中，1男中专，1男早逝，学历未知，1男大专。
总体来说，四女学历平均本科，出现两个高学历，一个985，一个211。六男里，一人前年出租屋自杀去世，学历未知，剩下五男，一个本科，一个大专，两个初中，一个中专。

两代人的职业对比

第一代五人职业分别是：

  1. 男1: 种地，卖菜（小学毕业）
  2. 女1: 卖胡辣汤（小学毕业）
  3. 女2: 养羊（小学毕业）
  4. 男2: 卖胡辣汤（高中毕业）
  5. 男3: 卖胡辣汤 + 开出租（小学毕业）

总体来说，第一代人职业分化并不大。且学历并没有在职业中起到明显作用。

第二代十个孩子职业分别是：

  1. 男1: 工厂车间管理（本科）
  2. 女1: 架构师（985）
  3. 男2: 工厂打零工（初中）
  4. 男3: 送外卖（学历未知，已去世）
  5. 男4：开货车（初中）
  6. 女2: 会计（本科）
  7. 女3: 剪辑（本科）
  8. 女4: 技术+AI（211）
  9. 男5: 销售（大专）
  10. 男6: 工厂小时工（中专）

总体来说，第二代人里，女孩学历+职业技能比男孩更稳定，学历在职业中，起到了较大作用，尤其女1学历985，小厂架构师，是这一代孩子的收入天花板和职业天花板。

两代人学历对比

  1. 男1: 本科
  2. 女1: 985本科 + 清华硕士
  3. 男2: 初中
  4. 男3: 学历未知，已经去世，不是本科，否则我早就该知道他了
  5. 男4：初中
  6. 女2: 本科
  7. 女3: 本科
  8. 女4: 211本科
  9. 男5: 大专
  10. 男6: 中专

总体来说，四女985+211率是50%。考虑到河南地区，985录取率是0.84%，211录取率2.6%，四女里两个985，211，占比50%，是很惊人了。四女本科率100%。考虑到河南本科率41%，四女本科率100%，也很惊人。
如果要更筛阶层的话，四女没有被额外培养教育，且家庭都是要么种地，要么卖胡辣汤，不是体制或者教师家庭，这么看，更惊人了（笑）。
六男这边，本科率是16.67%，低于河南平均本科录取率。

两代人婚姻对比

第一代无人婚姻状况对比：

  1. 男1: 25岁结婚，2子。
  2. 女1: 二十多岁结婚，1子1女。
  3. 女2: 二十多岁结婚，1子1女。
  4. 男2: 三十岁结婚，1女1子。
  5. 男3: 二十五岁结婚，1女1子。

五人无人离婚。皆有孩子。姑且算是婚姻稳定。

第二代人婚姻状况对比：

  1. 男1: 二十多岁结婚，1子1女。
  2. 女1: 二十八岁结婚，2女，还在要第三子。
  3. 男2: 二十六岁结婚，1子，对象三年后跑掉，目前光棍。
  4. 男4: 二十五岁结婚，1子1女，婚姻目前不稳，压力较大。
  5. 女2: 二十五岁结婚，1子1女，婚姻稳定。
  6. 男3: 去世，去世之前单身。
  7. 女3: 未婚。
  8. 女4: 未婚。
  9. 男5: 未婚。
  10. 男6: 未婚。

六男里，结婚的有两个，稳定婚姻的1个。结婚离婚老婆跑掉的1个。去世的1个，其余2个未婚。也就是目前走到上一代传宗接代的男，只有一个，比例是1/6。
四女里：结婚的2个，稳定婚姻的2个。未婚的2个。走到上一代老路里的，是1/2。

第二代四女的困境与原生家庭的关系

女1:

  • 架构师+985学历，已经结婚，目前在追三胎男孩，因为对方家是三代单传，不好不生。
  • 一开始学管理学不挣钱，干了一年工作之后，自费读研究生考上清华，然后转了技术，第一年毕业工资20万。后续在上海买了小公寓，在郑州买了房。
  • 婚前妈找她借了10万，拖了十多年，她去年把钱要回来了，她妈吐槽，居然要回来了。她吐槽：钱都给你儿子了。
  • 学历是自己读出来的，家长除了义务教育，无任何额外投资。读书时期，练习做太多，手指拿笔的关节上，有一个小凹坑。

女2:

  • 普通学历，兄弟去世，妈妈在兄弟去世葬礼上大骂她不孝。
  • 其余我并不清楚。只知道她是普通收入。

女3:

  • 普通本科，艺术生。文化课不好，父母花钱给她学艺术。
  • 剪辑师。加班多，工作辛苦。
  • 曾经抑郁症，据说原因是父母逼迫她跟外地男友分手，要求她必须跟本地男结婚。
  • 健康不大好，头发白了一半，早衰，169身高，90～100斤体重。
  • 剪辑三年平均工资5千/月，租房吃饭生活要吃掉3千，一个月能留两千多，三年给了父母三万。
  • 未婚。近期总因为催婚跟父母吵架。

女4:

  • 211本科。学到哪里上到哪里。没有任何额外补课。
  • 童年7～19岁寒暑假周六日给家里店当童工。童工日，每天上午6点半起床，10点半下班，下午18点吃完饭之后，干杂活儿到21点，之后洗漱睡觉。如果是旺季，童工日每天四点半起床，十一点半下班，下午18点吃完饭之后，干杂活儿到22点半，洗漱之后，11点睡觉。
  • 健康不好，慢性病，高血压频发。
  • 未婚。
  • 因催婚跟父母吵架吵到房早出现，心电图异常。
  • 生病期间，被父母托亲戚套话，问啥时候能病好上班去。

总体来说，四女虽然平均学历更高，职业护城河更好，但在我爹这一代家庭里，始终处于被安排，被消耗，被拖累，被收割的位置里。

第二代六男在原生家庭里的位置

男1:

  • 是女1的哥哥，女1，985，自己考上的。男1的学历，是父母花了十几万，打补丁，才最后打了个本科上去。
  • 家庭稳定，工作稳定，妻子工作也好，是六男里的天花板。虽然即便如此，跟女1比，还是逊色很多。
  • 父母的店铺，房产，存款，默认归男1。
  • 父母的照护责任+生病出钱，女1出大头，男1 出小头。

  • 给父母的礼物，十二年只有一个三千块的项链。

  • 去世原因是，被骗当担保人，欠了40万。精神崩溃。他妈怕他崩溃，就把手机号换成自己的，替他收催收短信，但他还是两年之后去世了，在陌生的出租屋自杀了。

  • 房子彩礼父母出了二十多万，因为给他盖的房子好，引起哥哥男2不满意。

男孩这边，学历天花板是男1，本科，还是父母花了十几万砸出来的。女孩这边，学历天花板是女1，985本科 + 研究生清华。
男孩这边，给父母钱最多的是男1，父母生病给了五千。女孩这边，给父母钱最多的是女1，被父母借走10万，父母以为不用还了。（笑）。当然，逢年过节，给父母发五千，生病给父母发一万五。

综上所述，我的同辈们，女孩投资回报比，比同辈男孩要高的多。（笑）。无论是职业/学历/家庭投资上。同时可以发现，男孩子这边，父母普遍投资了几十万上去。女孩这边，除了保证能活着之外，并无额外投资。

这种失衡，会导致什么？

  1. 我爹这一代男性老了以后，会出现照护真空。
    • 女儿没有拿到支持，不愿意照顾。
    • 儿子拿了支持但职业护城河/学历普遍不如女儿们，自己不稳，也无力照顾老人。
  2. 媳妇更难娶进来
    • 家庭怎么对待女儿，就会怎么对待媳妇。这一代的女儿们是被当耗材用的，那媳妇们嫁进来，会填补女儿们的位置
    • 但问题来了，现在00后90后男女比失衡，会导致这种性别角色极度功利化的家庭，非常难找媳妇。因为没有哪个女孩子，会想当几十年耗材。
    • 很多人以为，男女比失衡，是所有男生择偶机会一起下降，实际则是，更不拿女人当耗材的家庭，择偶机会上升更快，更拿女人当耗材的家庭，择偶机会被螺旋吸走。
  3. 家庭矛盾爆炸
    • 长期娶不到媳妇，本该分出家庭的男孩，被迫留在原生家庭里。导致家庭矛盾极易爆炸
    • 家庭照护资源缺失，导致更容易抓女儿来服劳役。最终导致能照顾老人的女儿继续跑路，不能照顾老人的儿子继续留在家里。
  4. 迷信更加盛行
    • 种种问题，导致老人和年轻人，更容易信神佛，信神婆，信谁克我们这类叙事。
  5. 下一代，也就是我侄子们这一代，不再那么容易抽到女1和女4这样的高学历了
    • 六男四女里，女1和女4这种旧式学霸式的孩子，很难再会有机会在未来考试竞争中脱颖而出了
    • 因为下一代的家庭不如上一代稳定，家庭压力大，孩子学习空间更窄了。
    • 其次，下一代孩子更拼家庭规划了，单纯的努力或者天赋，很难单打独斗出一个好结果了。但很明显第二代（10个孩子这一代）的家庭里，能有意识规划孩子的家庭不多。
    • 目前第三代，也就女1的孩子优秀。男2男4的孩子目前的成绩，以后想考985/211，机会渺茫。
