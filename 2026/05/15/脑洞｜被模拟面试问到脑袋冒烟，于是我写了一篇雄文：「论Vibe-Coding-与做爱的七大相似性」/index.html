脑洞｜被模拟面试问到脑袋冒烟，于是我写了一篇雄文：「论Vibe Coding 与做爱的七大相似性」

发表于 2026-05-15 10:51:21 更新于 2026-05-15 10:51:21 分类于 日常记录 ， 脑洞

语言反馈高度重合

vibe coding 时：

yes yes yes, 继续，就这样，别停，快把这个bug修了

做爱时：

yes yes yes, 继续，就这样，别停～

过程很爽，事后很空

vibe coding时：

我懂你需求，我帮你拆，我帮你写，我帮你重构

做完之后打开目录：

controller七个，service是三个，utils里躺着一堆不知道谁生的孩子

嗯，当时很上头，事后要负责

需求表达全靠对方领会

vibe coding的时候，命令模型：

感觉还差点意思
这里你应该懂吧

模型：

我不懂你说什么，但我会假装自己很懂，并且给你在项目里乱写800行看起来正确但一测试就露馅的代码

成瘾性极高

第一次vibe coding

哇，它真的能写～

第二次

我就让它帮我改一点点

第三次

算了，整个项目都塞给它生成吧

最后

没有codex，我不会开IDE
没有Claude，我不会起床
没有GPT，我不会做人

非常挑对象

喜欢Cursor的觉得

它在我 IDE 里，很贴身

喜欢Claude Code的觉得

它温柔，理解我，长上下文，很会陪跑

喜欢Codex的觉得

它硬核，能干活儿，还时不时重置额度

喜欢GPT的觉得

它不一定自己动手干活儿，但会先把我脑子扶正

嗯，非常的赛博择偶，非常的vibe coding

对持久度有要求

模型太快

你怎么两三秒就答完了，你真想了吗？

模型太慢

你在里面干什么呢？你是不是卡死了？

思考时间刚刚好

嗯……它在认真处理我

所以vibe coding最好的体验就是，要让用户时时刻刻都知道

别急，我还在里面呢

对尺寸有要求

vibe coding的时候，嘴上说

模型参数不重要

实际一听大模型，长上下文，深度推理，超大思维链，

哦，展开讲讲？

做爱的时候也是嘴上说

重要的是感觉

实际也偷偷比较各种硬指标
