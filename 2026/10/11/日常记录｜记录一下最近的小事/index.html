日常记录｜最近在做智能家居 + 任务看板 + 领AMD的GPU

发表于 2026-10-11 09:46:38 更新于 2026-10-11 09:46:38 分类于 日常记录

今天趁着GPT给我统计数据，我随便写写日常。

最近一年的节奏越来越快了。去年12月我开博客，到今年，写了358篇，单论今年写的，有293篇了。2026年1月1日到今天有283天了。几乎是日均一篇。
博客都是顺手写的，今年还改项目+智能家居+Agent+血糖控制+运动+处理冲突+回乡送亲+送往迎来。

今年体感是轮子转的越来越快，发呆的时间少了很多。
因为GPT+Claude能帮我处理任务了，它们处理任务期间，我就干干其他的，于是一不小心就同时开了四五个任务。

举个例子，今早我起来写博客，GPT处理博客语料分析（反正我自己的作品，随便分析），Codex帮我统计算法刷题情况，Claude来管智能家居，我等Apple Watch 30分钟倒计时结束打拳击。
也就是同时跑了5套上下文（博客，语料分析，算法情况，智能家居，拳击），所以体感虽然没做特别多的事情，但还是很容易困+累。

因为太多上下文，所以不得不把任务拆给GPT和Claude，或者我把所有待办事项扔给AI，讲明白几件没办法拖延的事情，然后其他事情让它们帮忙安排。
这样我不用多任务并行了。

最近看到AMD x 魔塔社区的GPU优惠活动，大概是注册AMD开发者+注册魔塔社区，领取100小时的GPU，我找GPT问了一下，这个有啥玩法？反正我的个人语料其实蛮多的。
日记：2019～2022，300篇左右（课程笔记，校内日常，小说，梦，人际分析，读书笔记，热点追踪等等）。
日记：2022～2025，300篇左右（店里日常，转行日常，家庭冲突，非虚构，梦，热点追踪，课程笔记等等）。
博客：2025～2026，358篇（AI，技术，小说，生活琐事，家庭冲突，社区冲突，健康，消费，算法等等）。

第一批日记不一定能找到。第二批我硬盘有。博客我现在就能分析。
所以大概有跨越7年（乐观点找到第一批日记）的语料。我这边日记大概是长短不一。不过多部分大概是2000+字，长篇写high了有5000+字，偶尔写短的，就是1000+字吧。

然后让GPT帮我找找玩法，反正原矿有了，GPU有了，就差操作工（本人）了（笑）。
哎呀，写到这里，想起来还没领GPU呢，立刻去领～（毕竟语料+操作工我这边随时都在，但GPU是外部资源，需要去领）。

试了试，领到了：

  • CPU 8核 32GB内存（长期使用）
  • CUDA GPU 8核，32GB内存，24GB显存（36小时）
  • AMD GPU 8核，200GB内存，192GB显存（100小时）

各自适用环境：

  • 24GB CUDA：跑PyTorch，常见开源模型，Embedding，LoRA微调实验
  • 192GB AMD环境：尝试更大参数的模型，本地大模型推理+显存密集型实验
  • CPU环境：写Python数据处理脚本，清洗数据，组织实验，验证数据流水线之类的

哇～蛮开心的～
找G和克给我估算了一下这次领取的优惠，如果按照市面租用，价格多少？
大概是1700～3000元左右，其中大头是AMD的那块192GB的MI300X卡，市价大约200～350美元～
算完，更开心了～（笑）

另一头，让Codex给我跑算法进度统计已经跑完了，我一直觉得算法没有刷完，但看刷题记录，已经覆盖了九成题目，剩下的就是收尾+二刷验证稳定性。
GPT帮我做的语料分析，也做完了V1.0版本，剩下的V2，要跑GPU上再继续进行了。

上午瞎折腾，总结如下：

  • 算法看板
  • 语料分析（博客）
  • 注册AMD账户+魔塔账户领CPU + GPU
  • 博客（这篇）

下午就做一点其他的：

  • 算法题
  • 上amd看看GPU具体型号
  • 把八股的看板做了
  • 把项目的看板做了

总体来说，是很轻的一天。
